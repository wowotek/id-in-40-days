## 2. Diskussion über Technologie-Nutzung

Verwenden Sie diese Strukturen, um darüber zu sprechen, wie Sie Technologie nutzen.

*   **Sprechen über die Nutzung:**
    *   `für die Arbeit` (untuk pekerjaan)
    *   `zur Kommunikation` (untuk komunikasi)
    *   `zur Unterhaltung` (untuk hiburan)

    *Beispiele:*
    *   `Ich benutze meinen Computer für die Arbeit.` (Saya menggunakan komputer saya untuk pekerjaan.)
    *   `Sie nutzt soziale Medien zur Kommunikation.` (Dia menggunakan media sosial untuk komunikasi.)

*   **Fragen nach Gewohnheiten:**
    *   `Nutzen Sie das Internet oft?` (Apakah kamu sering menggunakan internet?)
    *   `Wie kommunizieren Sie mit Ihrer Familie?` (Bagaimana kamu berkomunikasi dengan keluargamu?)

## 3. Häufige Ausdrücke zur Kommunikation

*   `Ruf mich an.` (Telepon saya.)
*   `Schreib mir eine Nachricht.` (Kirim pesan kepada saya.)
*   `Schreib mir eine E-Mail.` (Email saya.)
*   `In Kontakt bleiben.` (Tetap berhubungan.)

## 4. Nützliche Sätze

*   `Ich benutze mein Telefon jeden Tag.` (Saya menggunakan telepon saya setiap hari.)
*   `Haben Sie Internetzugang?` (Apakah kamu punya akses internet?)
*   `Ich schicke Ihnen eine E-Mail.` (Saya akan mengirim email kepadamu.)
*   `Lass uns online chatten.` (Mari kita mengobrol daring.)

## 5. Mini-Dialog

**A:** `Wie kommunizieren Sie normalerweise mit Ihren Freunden?` (Bagaimana kamu biasanya berkomunikasi dengan teman-temanmu?)
**B:** `Ich schreibe ihnen normalerweise Nachrichten oder benutze Social-Media-Apps.` (Saya biasanya mengirim pesan kepada mereka atau menggunakan aplikasi media sosial.)
**A:** `Nutzen Sie das Internet oft für Nachrichten?` (Apakah kamu sering menggunakan internet untuk berita?)
**B:** `Ja, ich durchsuche jeden Morgen Nachrichten-Webseiten.` (Ya, saya menjelajah situs web berita setiap pagi.)

## Übung

Übersetzen Sie die folgenden Sätze ins Indonesische:
