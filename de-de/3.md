# Tag 3 – Zahlen und Zeit

Heute lernst du, wie man auf Indonesisch zählt und die Uhrzeit angibt. Diese Fähigkeiten sind sehr nützlich für den Alltag!

---

| Indonesisch | Deutsch |
|-------------|--------------|
| nol         | null         |
| satu        | eins         |
| dua         | zwei         |
| tiga        | drei         |
| empat       | vier         |

| enam        | sechs        |

---

## ⏰ Uhrzeit angeben

| Indonesisch | Deutsch |
|-----------------------------------|-----------------------------------|
| Jam berapa sekarang?              | Wie spät ist es jetzt?            |
| Jam satu.                         | Es ist ein Uhr.                   |
| Jam dua belas siang.              | Es ist zwölf Uhr mittags.         |
| Jam tujuh malam.                  | Es ist sieben Uhr abends.         |
| Pukul tiga sore.                  | Es ist drei Uhr nachmittags.      |
| Setengah jam.                     | Eine halbe Stunde.                |
| Lima belas menit.                 | Fünfzehn Minuten.                 |

---

## 🕵️ Beispiel-Dialog

**Nach der Uhrzeit fragen:**

> **Du:** Jam berapa sekarang?
> 
> **Freund:** Jam delapan pagi.
> 
> **Du:** Danke.
> 
> **Freund:** Gern geschehen.

---

## 🧠 Übung

Übersetze ins Indonesische:

1. Es ist fünf Uhr.
2. Fünfundzwanzig Minuten.
3. Es ist neun Uhr.
4. Wie spät ist es jetzt?
5. Einhundert.

✅ _Antworten: 

1. Jam lima.
2. Dua puluh lima menit.
3. Jam sembilan.
4. Jam berapa sekarang?
5. Seratus.
