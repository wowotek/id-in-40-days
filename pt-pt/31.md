# Dia 31: Falar sobre Trabalho e Escola

## Introdução
Bem-vindo à lição do Dia 31! Hoje, vamos explorar o vocabulário e as expressões relacionadas ao trabalho e à escola. Isso o ajudará a falar sobre suas atividades diárias em relação ao trabalho ou estudo.

## Vocabulário Chave

| Português | Indonésio |
|---|---|
| trabalho | kerja |
| emprego | pekerjaan |
| empresa | perusahaan |
| escritório | kantor |
| colega de trabalho | rekan kerja |
| gerente | manajer |
| reunião | rapat |
| projeto | proyek |
| escola | sekolah |
| universidade | universitas |
| estudante | siswa/mahasiswa |
| professor/a | guru/dosen |

| aula | pelajaran |
| lição de casa | pekerjaan rumah |
| estudar | belajar |
| exame | ujian |
| biblioteca | perpustakaan |
| intervalo | istirahat |
| férias | liburan |

## Frases Úteis

*   **O que você faz?** (Apa pekerjaanmu?)
*   **Eu trabalho em uma empresa.** (Saya bekerja di perusahaan.)
*   **Eu sou estudante.** (Saya seorang siswa/mahasiswa.)
*   **Onde você estuda?** (Di mana kamu belajar?)
*   **Tenho uma reunião amanhã.** (Saya ada rapat besok.)
*   **Eu amo meu trabalho.** (Saya suka pekerjaan saya.)
*   **A escola é importante.** (Sekolah itu penting.)
*   **Você terminou sua lição de casa?** (Apakah kamu sudah menyelesaikan pekerjaan rumahmu?)
*   **Estamos aprendendo um novo idioma.** (Kami sedang belajar bahasa baru.)
*   **Quantas horas você trabalha por dia?** (Berapa jam kamu bekerja sehari?)

## Exercícios

1.  **Traduza as seguintes frases para o indonésio:**
    *   Eu vou para a universidade todos os dias.
    *   Meu chefe é muito legal.
    *   Qual é a sua matéria favorita na escola?

2.  **Descreva sua rotina diária no trabalho ou na escola em português.**

## Exemplo de Diálogo

**A:** Olá! O que você estuda na universidade?
**B:** Olá! Eu estudo Economia. E você? Você trabalha?
**A:** Sim, eu trabalho como engenheiro de software em uma empresa de tecnologia.
**B:** Isso é interessante! Você gosta do seu trabalho?
**A:** Sim, gosto muito. É desafiador e divertido.

## Conclusão
Parabéns por completar a lição do Dia 31! Agora você pode falar sobre trabalho e escola. Continue praticando essas expressões para dominá-las perfeitamente.
