# Dia 2 – Saudações e expressões básicas

Hoy aprenderás los saludos y las expresiones básicas en indonesio. ¡Estas frases son muy útiles en la conversación diaria!

---

## 👋 Vocabulario de Saludos y Expresiones Básicas

| Indonesio | Español |
|----------------|--------------------------|
| selamat pagi   | buenos días              |
| selamat siang  | buenas tardes (mañana)   |
| selamat sore   | buenas tardes (tarde)    |
| selamat malam  | buenas noches            |
| terima kasih   | gracias                  |
| sama-sama       | de nada                  |
| maaf           | lo siento/disculpa        |
| permisi        | disculpa (para llamar atención)|
| ya             | sí                       |
| tidak          | no                       |
| oke            | ok                       |

---

## 🗣️ Expresiones Básicas

| Indonesio | Español |
|-----------------------------------|--------------------------------------|
| Selamat pagi, Bapak.              | Buenos días, señor.                  |
| Terima kasih banyak.              | Muchas gracias.                      |
| Maaf, saya tidak mengerti.        | Lo siento, no entiendo.             |
| Permisi, toiletnya di mana?       | Disculpa, ¿dónde está el baño?       |
| Ya, saya mengerti.                | Sí, entiendo.                        |

---

## 🕵️ Diálogo de Ejemplo

**En un restaurante:**

> **Tú:** Permisi, bisa bantu?
> 
> **Camarero:** Ya, ada apa?
> 
> **Tú:** Terima kasih banyak.
> 
> **Camarero:** Sama-sama.

---

## 🧠 Práctica

Traduce al indonesio:

1. Buenas noches.
2. De nada.
3. Lo siento.
4. Sí.
5. No, gracias.

✅ _Clave de Respuestas:_

1. Selamat malam.
2. Sama-sama.
3. Maaf.
4. Ya.
5. Tidak, terima kasih.
