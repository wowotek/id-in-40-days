## 2. Discutindo o Uso da Tecnologia

Use estas estruturas para falar sobre como você usa a tecnologia.

*   **Falando sobre o uso:**
    *   `para trabalho` (untuk pekerjaan)
    *   `para comunicação` (untuk komunikasi)
    *   `para entretenimento` (untuk hiburan)

    *Exemplos:*
    *   `Eu uso meu computador para trabalho.` (Saya menggunakan komputer saya untuk pekerjaan.)
    *   `Ela usa as redes sociais para comunicação.` (Dia menggunakan media sosial untuk komunikasi.)

*   **Perguntando sobre hábitos:**
    *   `Você usa a internet com frequência?` (Apakah kamu sering menggunakan internet?)
    *   `Como você se comunica com sua família?` (Bagaimana kamu berkomunikasi dengan keluargamu?)

## 3. Expressões Comuns sobre Comunicação

*   `Ligue-me.` (Telepon saya.)
*   `Mande-me uma mensagem.` (Kirim pesan kepada saya.)
*   `Mande-me um e-mail.` (Email saya.)
*   `Mantenha contato.` (Tetap berhubungan.)

## 4. Frases Úteis

*   `Eu uso meu telefone todos os dias.` (Saya menggunakan telepon saya setiap hari.)
*   `Você tem acesso à internet?` (Apakah kamu punya akses internet?)
*   `Eu vou te mandar um e-mail.` (Saya akan mengirim email kepadamu.)
*   `Vamos conversar online.` (Mari kita mengobrol daring.)

## 5. Mini-Diálogo

**A:** `Como você geralmente se comunica com seus amigos?` (Bagaimana kamu biasanya berkomunikasi dengan teman-temanmu?)
**B:** `Eu geralmente mando mensagens para eles ou uso aplicativos de redes sociais.` (Saya biasanya mengirim pesan kepada mereka atau menggunakan aplikasi media sosial.)
**A:** `Você costuma usar a internet para notícias?` (Apakah kamu sering menggunakan internet untuk berita?)
**B:** `Sim, eu navego em sites de notícias todas as manhãs.` (Ya, saya menjelajah situs web berita setiap pagi.)
