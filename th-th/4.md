# วันที่ 4 – โครงสร้างประโยคพื้นฐาน

เมื่อคุณได้เรียนรู้คำสรรพนามส่วนตัวแล้ว ก็ถึงเวลาที่จะเริ่ม**สร้างประโยคเต็ม**

ข่าวดี: **โครงสร้างประโยคภาษาอินโดนีเซียนั้นเรียบง่ายและสอดคล้องกัน** แตกต่างจากภาษาในยุโรปหลายภาษา คือ**ไม่มีการผันคำกริยา** **ไม่มีคำนำหน้านาม** และ**ไม่มีคำนามที่มีเพศ** — ซึ่งทำให้เรียนรู้ได้ง่ายมาก

## 📐 รูปแบบประโยคพื้นฐาน

โครงสร้างที่พบบ่อยที่สุดในภาษาอินโดนีเซียคือ:

- **ประธาน + กริยา + กรรม**
- (S + V + O)

ซึ่งเหมือนกับภาษาอังกฤษ

## 🧱 ตัวอย่าง

| อังกฤษ                     | อินโดนีเซีย               |
|----------------------------|--------------------------|
| I eat rice.                | **Saya makan nasi.**     |
| You read a book.           | **Kamu baca buku.**      |
| He drinks water.           | **Dia minum air.**       |
| We study Indonesian.       | **Kita belajar bahasa Indonesia.** |
| They watch a movie.        | **Mereka nonton film.**  |

> 📝 คำกริยาเช่น *makan (กิน)* และ *minum (ดื่ม)* **ไม่**เปลี่ยนแปลงตามกาล

## ⏱ กาลในภาษาอินโดนีเซีย

ภาษาอินโดนีเซีย**ไม่มี**การผันคำกริยาสำหรับอดีต ปัจจุบัน หรืออนาคต

แต่จะใช้**เครื่องหมายบอกเวลา**แทน:

| เครื่องหมายบอกเวลา | ความหมาย           | ประโยคตัวอย่าง                            |
|-------------------|--------------------|------------------------------------------|
| **sudah**         | แล้ว (อดีต)         | Saya **sudah** makan. = ฉันกินแล้ว       |
| **belum**         | ยังไม่ได้          | Kamu **belum** tidur? = คุณยังไม่นอนเหรอ? |
| **sedang**        | กำลัง (ปัจจุบัน)     | Dia **sedang** belajar. = เขา/เธอกำลังเรียน |
| **akan**          | จะ (อนาคต)         | Kami **akan** pergi. = เราจะไป            |
| **tadi**          | ก่อนหน้านี้ในวันนี้ | Saya makan **tadi**. = ฉันกินเมื่อกี้นี้ |
| **nanti**         | ภายหลัง            | Kita pergi **nanti**. = เราจะไปทีหลัง     |

## 🗣️ ฝึกแต่งประโยค

สร้างประโยคโดยใช้โครงสร้าง:

- **Saya + [คำกริยา] + [กรรม]**
- **Dia + [คำกริยา] + [กรรม]**
- **Kita + akan + [คำกริยา] + [กรรม]**

ตัวอย่าง:

1.  Saya baca buku. – ฉันอ่านหนังสือ
2.  Dia sudah makan. – เขา/เธอกินแล้ว
3.  Kita akan belajar. – เราจะเรียน
4.  Mereka minum kopi. – พวกเขาดื่มกาแฟ
5.  Kamu sedang tidur. – คุณกำลังนอนหลับ

## ❗️ประโยคปฏิเสธ

ในการสร้างประโยคปฏิเสธ:

| คำ       | กรณีการใช้                     | ตัวอย่าง                              |
|----------|------------------------------|--------------------------------------|
| **tidak**| สำหรับคำกริยาและคำคุณศัพท์   | Saya **tidak** makan. = ฉันไม่กิน      |
| **bukan**| สำหรับคำนามหรือการแก้ไข     | Itu **bukan** buku saya. = นั่นไม่ใช่หนังสือของฉัน |

## 🧠 เพิ่มคำศัพท์

| คำศัพท์      | ความหมาย       |
|-------------|----------------|
| makan       | กิน            |
| minum       | ดื่ม           |
| baca        | อ่าน           |
| belajar     | เรียน          |
| tidur       | นอน           |
| pergi       | ไป            |
| buku        | หนังสือ        |
| nasi        | ข้าว           |
| air         | น้ำ            |
| film        | ภาพยนตร์       |

## 🚀 ความท้าทายประจำวัน

เขียนประโยคบอกเล่า 3 ประโยคและประโยคปฏิเสธ 2 ประโยคในภาษาอินโดนีเซียโดยใช้โครงสร้าง:

- ประธาน + (เครื่องหมายบอกเวลา) + กริยา + กรรม

ตัวอย่าง:

- Saya sudah minum air.
- Kamu akan baca buku.
- Kita belajar bahasa Indonesia.
- Saya **tidak** pergi.
- Itu **bukan** film baru.
