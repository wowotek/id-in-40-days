# วันที่ 5 – ตัวเลข (1–100)

วันนี้คุณจะได้เรียนรู้การนับเลขใน**ภาษาอินโดนีเซีย** — ซึ่งเป็นสิ่งจำเป็นสำหรับชีวิตประจำวัน: การซื้อของ, เวลา, วันที่, และอื่นๆ

ตัวเลขภาษาอินโดนีเซียนั้น**ปกติและมีเหตุผล** โดยแทบไม่มีรูปแบบที่ผิดปกติ เมื่อคุณเรียนรู้รูปแบบแล้ว คุณสามารถนับได้สูงเท่าที่คุณต้องการ!

## 🔢 ตัวเลข 1–10

| ตัวเลข | อินโดนีเซีย |
|--------|------------|
| 1      | satu       |
| 2      | dua        |
| 3      | tiga       |
| 4      | empat      |
| 5      | lima       |
| 6      | enam       |
| 7      | tujuh      |
| 8      | delapan    |
| 9      | sembilan   |
| 10     | sepuluh    |

## 🔟 เลขหลักสิบ (11–19)

| ตัวเลข | อินโดนีเซีย  | หมายเหตุ                         |
|--------|--------------|----------------------------------|
| 11     | sebelas      | รูปแบบพิเศษ (ไม่ใช่ "se-satu") |
| 12     | dua belas    | 2 + belas                        |
| 13     | tiga belas   | 3 + belas                        |
| ...    | ...          |                                  |
| 19     | sembilan belas |                                |

> "Belas" เป็นคำต่อท้ายสำหรับตัวเลขหลักสิบ (-teen)

## 🧮 หลักสิบ (20, 30, ..., 90)

| ตัวเลข | อินโดนีเซีย      | รูปแบบ                   |
|--------|------------------|--------------------------|
| 20     | dua puluh        | 2 × 10                   |
| 30     | tiga puluh       | 3 × 10                   |
| 40     | empat puluh      | ...                      |
| 50     | lima puluh       |                          |
| 60     | enam puluh       |                          |
| 70     | tujuh puluh      |                          |
| 80     | delapan puluh    |                          |
| 90     | sembilan puluh   |                          |

## 🧩 การสร้างตัวเลข (21–99)

ใช้รูปแบบนี้:

> **[หลักสิบ] + [หลักหน่วย]**

ตัวอย่าง:

- 21 = dua puluh satu
- 35 = tiga puluh lima
- 48 = empat puluh delapan
- 99 = sembilan puluh sembilan

## 💯 หนึ่งร้อย

| ตัวเลข | อินโดนีเซีย |
|--------|------------|
| 100    | seratus    |
| 200    | dua ratus  |
| 300    | tiga ratus |
| 400    | empat ratus|

> "Se-" เป็นคำย่อของ **satu** ดังนั้น "seratus" = *หนึ่งร้อย*
> 200 = **dua ratus**, 300 = **tiga ratus**, และอื่นๆ

## 🎙️ ฝึกอ่าน

พูดคำเหล่านี้ออกมาดังๆ:

- Saya punya **dua belas** teman. → ฉันมีเพื่อนสิบสองคน
- Harganya **tiga puluh lima ribu rupiah**. → ราคาคือ 35,000 รูเปียห์
- Nomor teleponnya **sembilan delapan tujuh...** → หมายเลขโทรศัพท์คือ 987...

## 🧠 เพิ่มคำศัพท์

| คำศัพท์      | ความหมาย            |
|-------------|---------------------|
| angka       | ตัวเลข              |
| harga       | ราคา                |
| rupiah      | สกุลเงินอินโดนีเซีย |
| nomor       | หมายเลข (เช่น ID หรือโทรศัพท์) |
| teman       | เพื่อน              |
| punya       | มี/เป็นเจ้าของ      |

## 🚀 ความท้าทายประจำวัน
