# วันที่ 3 – คำสรรพนามส่วนตัว (ฉัน, คุณ, เรา…)

การเข้าใจ**คำสรรพนามส่วนตัว**เป็นสิ่งจำเป็นสำหรับการสร้างประโยคพื้นฐาน คำสรรพนามภาษาอินโดนีเซียนั้น**ตรงไปตรงมา** **เป็นกลางทางเพศ** และ**ไม่เปลี่ยนแปลงตามกาล** – ซึ่งทำให้เรียนรู้ได้ง่ายมาก

---

## 👤 คำสรรพนามเอกพจน์

| อังกฤษ     | อินโดนีเซีย        | หมายเหตุ                                                |
|-------------|-------------------|---------------------------------------------------------|
| I / Me      | **Saya** / **Aku** | "Saya" เป็นทางการ / สุภาพ "Aku" เป็นกันเอง / ใกล้ชิด |
| You         | **Kamu** / **Anda** | "Kamu" เป็นกันเอง "Anda" เป็นทางการ / สุภาพ            |
| He / She    | **Dia**            | ไม่มีการแบ่งเพศ                                          |
| It          | *(ไม่ใช้โดยตรง)*   | ภาษาอินโดนีเซียไม่ค่อยใช้ "it" ให้ใช้ **itu** = *นั่น*     |

---

## 👥 คำสรรพนามพหูพจน์

| อังกฤษ             | อินโดนีเซีย | หมายเหตุ                                                  |
|--------------------|------------|-----------------------------------------------------------|
| We (รวมผู้ฟัง)     | **Kita**   | รวมคนที่คุณกำลังพูดด้วย                                    |
| We (ไม่รวมผู้ฟัง) | **Kami**   | ไม่รวมคนที่คุณกำลังพูดด้วย                                 |
| You (พหูพจน์)      | **Kalian** | "พวกคุณ" แบบไม่เป็นทางการ                                |
| They               | **Mereka** | สำหรับกลุ่มคนใดๆ                                          |

> 🧠 ไม่มีรูปแบบเพศชาย/หญิงแยกต่างหาก "Dia" ใช้ได้ทั้งเขา/เธอ

---

## 🗣️ ประโยคตัวอย่าง

- **Saya suka kopi.** → ฉันชอบกาแฟ
- **Dia pintar.** → เขา/เธอฉลาด
- **Kami pergi ke pasar.** → พวกเรา (ไม่รวมคุณ) กำลังไปตลาด
- **Kita belajar bersama.** → พวกเรา (รวมคุณ) กำลังเรียนด้วยกัน
- **Kalian lucu sekali.** → พวกคุณตลกมาก
- **Mereka tinggal di Jakarta.** → พวกเขาอาศัยอยู่ในจาการ์ตา

---

## 🔄 เปรียบเทียบอย่างรวดเร็ว: Saya vs Aku

| ลักษณะ         | Saya              | Aku                  |
|----------------|-------------------|----------------------|
| ความเป็นทางการ | สุภาพ / เป็นกลาง  | เป็นกันเอง / แสดงอารมณ์ |
| บริบทการใช้งาน | ธุรกิจ, การเขียน, คนแปลกหน้า | เพื่อน, ครอบครัว, คู่รัก |
| ปลอดภัยสำหรับ... | ทุกสถานการณ์       | ความสัมพันธ์ใกล้ชิด    |

---

## 👀 ข้อควรทราบทางวัฒนธรรม

- “**Anda**” เป็นทางการ, สุภาพ, และห่างเหิน — ใช้ในการบริการลูกค้า, การโฆษณา, หรือการพูดอย่างเป็นทางการ
- ในการสนทนาในชีวิตประจำวัน คนส่วนใหญ่ใช้ **"kamu"** หรือแทนที่คำสรรพนามด้วยชื่อ/ตำแหน่ง เช่น **mas**, **mbak**, หรือแค่ชื่อของบุคคลนั้น — โดยเฉพาะในภูมิภาคที่พูดภาษาชวา

---

## 🧠 เพิ่มคำศัพท์

| อินโดนีเซีย | ความหมาย          |
|------------|-------------------|
| saya       | ฉัน / ผม (เป็นทางการ) |
| aku        | ฉัน / ผม (ไม่เป็นทางการ)|
| kamu       | คุณ (ไม่เป็นทางการ) |
| anda       | คุณ (เป็นทางการ)  |
| dia        | เขา / เธอ         |
| kita       | เรา (รวมผู้ฟัง)   |
| kami       | เรา (ไม่รวมผู้ฟัง) |
| mereka     | พวกเขา            |
| kalian     | พวกคุณ            |

---

## 🚀 ความท้าทายประจำวัน

เขียน 5 ประโยคสั้นๆ โดยใช้คำสรรพนามที่แตกต่างกัน ตัวอย่าง:

1.  **Saya** suka nasi goreng.
2.  **Kamu** pergi ke sekolah.
3.  **Dia** tidur.
4.  **Kita** makan bersama.
5.  **Mereka** belajar bahasa Indonesia.
