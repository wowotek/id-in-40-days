# วันที่ 34: เทคโนโลยีและการสื่อสาร

## สารบัญ

1.  **คำศัพท์เทคโนโลยี**
    *   คำศัพท์สำหรับอุปกรณ์ทั่วไป (โทรศัพท์, คอมพิวเตอร์, อินเทอร์เน็ต, อีเมล, สื่อสังคมออนไลน์)
    *   กริยาที่เกี่ยวข้องกับเทคโนโลยี (ส่ง, รับ, ท่อง, พิมพ์)
2.  **การพูดคุยเกี่ยวกับการใช้เทคโนโลยี**
    *   การพูดคุยเกี่ยวกับการใช้เทคโนโลยีของคุณ (เพื่อการทำงาน, เพื่อการสื่อสาร, เพื่อความบันเทิง)
    *   การสอบถามเกี่ยวกับพฤติกรรมการใช้เทคโนโลยีของผู้อื่น
3.  **สำนวนทั่วไปเกี่ยวกับการสื่อสาร**
    *   "โทรหาฉัน", "ส่งข้อความหาฉัน", "ส่งอีเมลหาฉัน"
    *   "ติดต่อกันไว้"
4.  **วลีที่เป็นประโยชน์**
    *   "ฉันใช้โทรศัพท์ทุกวัน"
    *   "คุณมีอินเทอร์เน็ตหรือไม่?"
    *   "ฉันจะส่งอีเมลให้คุณ"
    *   "มาคุยกันออนไลน์"
5.  **บทสนทนาสั้นๆ**
    *   การสนทนาเกี่ยวกับการใช้เทคโนโลยีเพื่อสื่อสาร

## 1. คำศัพท์เทคโนโลยี

เรียนรู้คำศัพท์สำคัญที่เกี่ยวข้องกับเทคโนโลยีและการสื่อสาร

| ไทย                 | อินโดนีเซีย    |
|--------------------|----------------|
| โทรศัพท์            | telepon        |
| คอมพิวเตอร์         | komputer       |
| อินเทอร์เน็ต         | internet       |
| อีเมล               | email          |
| สื่อสังคมออนไลน์   | media sosial   |
| เว็บไซต์           | situs web      |
| แอปพลิเคชัน (แอป)  | aplikasi       |
| ข้อความ             | pesan          |
| ส่ง                 | mengirim       |
| รับ                 | menerima       |
| ท่อง                | menjelajah     |
| พิมพ์               | mengetik       |
| โทร                 | menelepon      |
| ส่งข้อความ          | mengirim pesan |
| สื่อสาร             | berkomunikasi  |

## 2. การพูดคุยเกี่ยวกับการใช้เทคโนโลยี

ใช้โครงสร้างเหล่านี้เพื่อพูดคุยเกี่ยวกับวิธีที่คุณใช้เทคโนโลยี

*   **การพูดคุยเกี่ยวกับการใช้งาน:**
    *   `เพื่อการทำงาน` (untuk pekerjaan)
    *   `เพื่อการสื่อสาร` (untuk komunikasi)
    *   `เพื่อความบันเทิง` (untuk hiburan)

    *ตัวอย่าง:*
    *   `ฉันใช้คอมพิวเตอร์เพื่อการทำงาน` (Saya menggunakan komputer saya untuk pekerjaan.)
    *   `เธอใช้สื่อสังคมออนไลน์เพื่อการสื่อสาร` (Dia menggunakan media sosial untuk komunikasi.)

*   **การสอบถามเกี่ยวกับพฤติกรรม:**
    *   `คุณใช้อินเทอร์เน็ตบ่อยไหม?` (Apakah kamu sering menggunakan internet?)
    *   `คุณสื่อสารกับครอบครัวอย่างไร?` (Bagaimana kamu berkomunikasi dengan keluargamu?)

## 3. สำนวนทั่วไปเกี่ยวกับการสื่อสาร

*   `โทรหาฉัน` (Telepon saya.)
*   `ส่งข้อความหาฉัน` (Kirim pesan kepada saya.)
*   `ส่งอีเมลหาฉัน` (Email saya.)
*   `ติดต่อกันไว้` (Tetap berhubungan.)

## 4. วลีที่เป็นประโยชน์

*   `ฉันใช้โทรศัพท์ทุกวัน` (Saya menggunakan telepon saya setiap hari.)
*   `คุณมีอินเทอร์เน็ตหรือไม่?` (Apakah kamu punya akses internet?)
*   `ฉันจะส่งอีเมลให้คุณ` (Saya akan mengirim email kepadamu.)
*   `มาคุยกันออนไลน์` (Mari kita mengobrol daring.)

## 5. บทสนทนาสั้นๆ

**A:** `คุณสื่อสารกับเพื่อนๆ อย่างไรบ้าง?` (Bagaimana kamu biasanya berkomunikasi dengan teman-temanmu?)
**B:** `ฉันมักจะส่งข้อความหาพวกเขา หรือใช้แอปพลิเคชันสื่อสังคมออนไลน์` (Saya biasanya mengirim pesan kepada mereka atau menggunakan aplikasi media sosial.)
**A:** `คุณใช้อินเทอร์เน็ตเพื่ออ่านข่าวบ่อยไหม?` (Apakah kamu sering menggunakan internet untuk berita?)
**B:** `ใช่ ฉันท่องเว็บไซต์ข่าวทุกเช้า` (Ya, saya menjelajah situs web berita setiap pagi.)

## แบบฝึกหัด

แปลประโยคต่อไปนี้เป็นภาษาอินโดนีเซีย:

1.  ฉันต้องตรวจสอบอีเมลของฉัน
2.  เธอส่งข้อความหาฉัน
3.  อินเทอร์เน็ตที่นี่เร็วมาก

**เฉลย:**

1.  Saya perlu memeriksa email saya.
2.  Dia mengirimi saya pesan.
3.  Internet di sini sangat cepat.
