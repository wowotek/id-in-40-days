# วันที่ 11 – การถามเส้นทาง 🧭

วันนี้ คุณจะได้เรียนรู้วิธี**ถามและเข้าใจเส้นทาง**โดยใช้ภาษาอินโดนีเซียแบบง่ายๆ — ไม่มีคำนำหน้า ไม่มีคำต่อท้าย

สิ่งนี้มีประโยชน์อย่างยิ่งเมื่อเดินทาง ค้นหาสถานที่ หรือขอความช่วยเหลือจากคนท้องถิ่น

## 🧭 วลีคำถามสำคัญ

| อังกฤษ                 | อินโดนีเซีย (แบบง่าย)         |
|------------------------|-------------------------------|
| Where is [place]?      | [สถานที่] **di mana**?        |
| How to go to [place]?  | **Bagaimana ke** [สถานที่]?   |
| Where are you going?   | **Kamu ke mana**?             |
| Is it far?             | **Jauh tidak?**               |
| Left or right?         | **Kiri atau kanan?**          |

## 🏙️ คำศัพท์ทิศทางที่สำคัญ

| อินโดนีเซีย | อังกฤษ         |
|------------|----------------|
| kiri       | ซ้าย           |
| kanan      | ขวา            |
| lurus      | ตรงไป          |
| belok      | เลี้ยว         |
| dekat      | ใกล้           |
| jauh       | ไกล            |
| lampu merah| ไฟจราจร       |
| jalan      | ถนน / ซอย      |
| pasar      | ตลาด           |
| toko       | ร้านค้า        |

## 🏃‍♂️ วลีที่พบบ่อย

| อังกฤษ                        | อินโดนีเซีย (แบบง่าย)           |
|-------------------------------|----------------------------------|
| Go straight                   | **Lurus** saja                   |
| Turn left                     | **Belok kiri**                   |
| Turn right                    | **Belok kanan**                  |
| It's near                     | **Dekat** saja                   |
| It's far                      | **Jauh sekali**                  |
| Go to the market              | **Ke pasar**                     |
| Where is the station?         | **Stasiun di mana?**            |
| How to go to the mosque?      | **Bagaimana ke masjid?**        |

> 💡 คุณสามารถพูด **saja** เพื่อหมายถึง "แค่" หรือ "เท่านั้น" และ **sekali** เพื่อหมายถึง "มาก"

## 🧠 เพิ่มคำศัพท์

| คำศัพท์      | ความหมาย         |
|-------------|------------------|
| masjid      | มัสยิด           |
| stasiun     | สถานี           |
| bandara     | สนามบิน         |
| sekolah     | โรงเรียน         |
| rumah sakit | โรงพยาบาล       |
| hotel       | โรงแรม           |
| mol         | ห้างสรรพสินค้า   |

## 🗺️ ตัวอย่างบทสนทนา

**A**: Permisi, pasar di mana?
**B**: Lurus saja, lalu belok kanan.
**A**: Dekat?
**B**: Ya, dekat.

> A: ขอโทษครับ/ค่ะ ตลาดอยู่ที่ไหนครับ/คะ?
> B: ตรงไปครับ/ค่ะ แล้วเลี้ยวขวา
> A: ใกล้ไหมครับ/คะ?
> B: ใช่ครับ/ค่ะ ใกล้ครับ/ค่ะ

## 🚀 ความท้าทายประจำวัน

แปลและพูดสิ่งเหล่านี้เป็นภาษาอินโดนีเซีย:

1.  Where is the school?
2.  How to go to the hospital?
3.  Turn left at the traffic light.
4.  Is the mall far?
5.  I want to go to the station.

**โบนัส:** ลองถามเพื่อนหรือคนท้องถิ่นโดยใช้ *di mana*!
