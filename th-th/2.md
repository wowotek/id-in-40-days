# วันที่ 2 – คำทักทายและการแนะนำตัวพื้นฐาน
หนึ่งในขั้นตอนแรกสู่การเรียนรู้ภาษาใดๆ คือการทักทายผู้คนและแนะนำตัวเอง ในภาษาอินโดนีเซีย คำทักทายนั้นง่าย เป็นมิตร และยืดหยุ่น คุณจึงสามารถใช้ได้ทุกวัน

## คำทักทายทั่วไป
| อินโดนีเซีย         | ความหมาย                      | หมายเหตุ                          |
| ------------------- | ----------------------------- | --------------------------------- |
| **Halo**            | สวัสดี                        | ใช้ได้ทั่วไปและเป็นกันเอง          |
| **Selamat pagi**    | อรุณสวัสดิ์                   | ใช้จนถึงประมาณ 11 โมงเช้า         |
| **Selamat siang**   | สวัสดีตอนกลางวัน / บ่ายต้นๆ   | ตั้งแต่ประมาณ 11 โมงเช้าถึงบ่าย 3 โมง |
| **Selamat sore**    | สวัสดีตอนบ่าย / เย็น           | ตั้งแต่ประมาณบ่าย 3 โมงถึงพระอาทิตย์ตก |
| **Selamat malam**   | ราตรีสวัสดิ์ / กลางคืน         | หลังพระอาทิตย์ตก                  |
| **Apa kabar?**      | สบายดีไหม?                   | เป็นกันเองและเป็นมิตร             |
| **Baik.**           | สบายดี                      | คำตอบมาตรฐาน                      |
| **Baik-baik saja.** | สบายดีมาก                    | เป็นทางการขึ้นเล็กน้อย             |

## การแนะนำตัวเอง
| อังกฤษ               | อินโดนีเซีย                          | ตัวอย่าง                         |
| ------------------- | ------------------------------------ | --------------------------------- |
| My name is...       | **Nama saya...**                     | Nama saya John. (ฉันชื่อจอห์น)     |
| I am...             | **Saya...**                          | Saya pelajar. (ฉันเป็นนักเรียน)  |
| Nice to meet you    | **Senang bertemu denganmu**          | สุภาพและเป็นมิตร                  |
| Where are you from? | **Dari mana?** / **Asal dari mana?** | เป็นกันเองและมีประโยชน์             |
| I'm from...         | **Saya dari...**                     | Saya dari Amerika. (ฉันมาจากอเมริกา)|

## การกล่าวลา
| อินโดนีเซีย         | ความหมาย                           | หมายเหตุ                                 |
| ------------------- | ---------------------------------- | ---------------------------------------- |
| **Sampai jumpa!**   | แล้วพบกัน!                         | ตรงตัว: "จนกว่าเราจะพบกันอีกครั้ง"      |
| **Sampai nanti!**   | แล้วพบกันใหม่!                     | "จนกว่าจะถึงภายหลัง"                      |
| **Selamat tinggal** | ลาก่อน (เมื่อ *คุณ* ยังอยู่ที่เดิม) | ใช้เมื่ออีกฝ่ายหนึ่งกำลังจะไป               |
| **Selamat jalan**   | ลาก่อน (เมื่อ *พวกเขา* ยังอยู่ที่เดิม)| ใช้เมื่อ *คุณ* กำลังจะไป                  |

# ประโยคฝึกหัด
พูดประโยคเหล่านี้ออกมาดังๆ การฝึกฝนทำให้คล่องแคล่ว!

- Halo, nama saya Anna.
- Selamat pagi! Apa kabar?
- Saya dari Jepang.
- Senang bertemu denganmu!
- Sampai jumpa besok!

# เพิ่มคำศัพท์
| คำศัพท์      | ความหมาย                  |
| --------- | ------------------------ |
| **pagi**  | ตอนเช้า                  |
| **siang** | กลางวัน / บ่ายต้นๆ        |
| **sore**  | บ่ายแก่ๆ                  |
| **malam** | กลางคืน                  |
| **saya**  | ฉัน / ผม                  |
| **nama**  | ชื่อ                     |
| **baik**  | ดี / สบายดี               |
| **dari**  | จาก                      |
| **jumpa** | พบ                       |
