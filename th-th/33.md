# วันที่ 33: การเฉลิมฉลองและวันหยุด

## สารบัญ

1.  **คำศัพท์วันหยุด**
    *   ชื่อวันหยุดทั่วไป (ปีใหม่, วันอีดิลฟิฏริ, คริสต์มาส, ดิสวาลี, ฯลฯ)
    *   คำศัพท์ที่เกี่ยวข้องกับการเฉลิมฉลอง (งานเลี้ยง, ของขวัญ, เค้ก, ตกแต่ง)
2.  **การพูดคุยเกี่ยวกับประเพณีวันหยุด**
    *   การพูดคุยเกี่ยวกับกิจกรรมในวันหยุด (เยี่ยมครอบครัว, กินอาหารพิเศษ)
    *   การแสดงความปรารถนาดีสำหรับวันหยุด
3.  **สำนวนทั่วไปเกี่ยวกับการเฉลิมฉลอง**
    *   "สวัสดีปีใหม่", "สุขสันต์วันคริสต์มาส", "สุขสันต์วันอีด"
    *   "ขอให้มีความสุขในวันหยุด"
4.  **วลีที่เป็นประโยชน์**
    *   "คุณมีแผนอะไรสำหรับวันหยุด?"
    *   "เราฉลองวันอีดิลฟิฏริทุกปี"
    *   "ฉันชอบให้ของขวัญ"
    *   "งานเลี้ยงสนุกมาก"
5.  **บทสนทนาสั้นๆ**
    *   การสนทนาเกี่ยวกับแผนและประเพณีในวันหยุด

## 1. คำศัพท์วันหยุด

เรียนรู้คำศัพท์สำคัญที่เกี่ยวข้องกับการเฉลิมฉลองและวันหยุด

| ไทย                 | อินโดนีเซีย    |
|--------------------|----------------|
| วันปีใหม่           | Tahun Baru     |
| วันอีดิลฟิฏริ       | Idul Fitri     |
| คริสต์มาส          | Natal          |
| ดิสวาลี            | Diwali         |
| ตรุษจีน             | Imlek          |
| วันประกาศอิสรภาพ   | Hari Kemerdekaan |
| วันเกิด             | ulang tahun    |
| วันหยุด             | hari libur     |
| งานเลี้ยง           | pesta          |
| ของขวัญ            | hadiah         |
| เค้ก                | kue            |
| ตกแต่ง             | menghias       |
| เฉลิมฉลอง           | merayakan      |

## 2. การพูดคุยเกี่ยวกับประเพณีวันหยุด

ใช้โครงสร้างเหล่านี้เพื่อพูดคุยเกี่ยวกับกิจกรรมและประเพณีในวันหยุด

*   **การพูดคุยเกี่ยวกับกิจกรรม:**
    *   `เยี่ยมครอบครัว` (mengunjungi keluarga)
    *   `กินอาหารพิเศษ` (makan makanan khusus)
    *   `แลกเปลี่ยนของขวัญ` (bertukar hadiah)

    *ตัวอย่าง:*
    *   `เราไปเยี่ยมครอบครัวในช่วงวันอีดิลฟิฏริ` (Kami mengunjungi keluarga saat Idul Fitri.)
    *   `พวกเขากินเค้กพิเศษสำหรับคริสต์มาส` (Mereka makan kue khusus untuk Natal.)

*   **การแสดงความปรารถนาดี:**
    *   `สวัสดีปีใหม่!` (Selamat Tahun Baru!)
    *   `สุขสันต์วันคริสต์มาส!` (Selamat Natal!)
    *   `สุขสันต์วันอีด!` (Selamat Idul Fitri!)

## 3. สำนวนทั่วไปเกี่ยวกับการเฉลิมฉลอง

*   `สุขสันต์วันเกิด!` (Selamat ulang tahun!)
*   `ขอให้มีความสุขในวันหยุด!` (Selamat berlibur!)
*   `ขอให้สนุก!` (Selamat bersenang-senang!)

## 4. วลีที่เป็นประโยชน์

*   `คุณมีแผนอะไรสำหรับวันหยุด?` (Apa rencanamu untuk liburan?)
*   `เราฉลองวันอีดิลฟิฏริทุกปี` (Kami merayakan Idul Fitri setiap tahun.)
*   `ฉันชอบให้ของขวัญ` (Saya suka memberi hadiah.)
*   `งานเลี้ยงสนุกมาก` (Pestanya menyenangkan.)

## 5. บทสนทนาสั้นๆ

**A:** `คุณมีแผนอะไรสำหรับวันปีใหม่?` (Apa rencanamu untuk Tahun Baru?)
**B:** `ฉันจะไปเยี่ยมครอบครัวและเราจะมีงานเลี้ยง` (Saya akan mengunjungi keluarga saya dan kami akan mengadakan pesta.)
**A:** `ฟังดูสนุกนะ! คุณจะแลกเปลี่ยนของขวัญไหม?` (Kedengarannya menyenangkan! Akankah kalian bertukar hadiah?)
**B:** `ใช่ เราทำอย่างนั้นเสมอ และเราจะกินเค้กพิเศษ` (Ya, kami selalu begitu. Dan kami akan makan kue khusus.)
