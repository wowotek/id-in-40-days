# दिन 34: प्रौद्योगिकी और संचार

## सामग्री की तालिका

1.  **प्रौद्योगिकी शब्दावली**
    *   सामान्य उपकरणों के लिए शब्द (फोन, कंप्यूटर, इंटरनेट, ईमेल, सोशल मीडिया)
    *   प्रौद्योगिकी से संबंधित क्रियाएँ (भेजना, प्राप्त करना, ब्राउज़ करना, टाइप करना)
2.  **प्रौद्योगिकी उपयोग पर चर्चा**
    *   आप प्रौद्योगिकी का उपयोग कैसे करते हैं, इस बारे में बात करना (काम के लिए, संचार के लिए, मनोरंजन के लिए)
    *   दूसरों की प्रौद्योगिकी आदतों के बारे में पूछना
3.  **संचार के बारे में सामान्य अभिव्यक्तियाँ**
    *   "मुझे फोन करो", "मुझे टेक्स्ट करो", "मुझे ईमेल करो"
    *   "संपर्क में रहना"
4.  **उपयोगी वाक्यांश**
    *   "मैं हर दिन अपने फोन का उपयोग करता हूँ।"
    *   "क्या आपके पास इंटरनेट तक पहुँच है?"
    *   "मैं आपको एक ईमेल भेजूंगा।"
    *   "चलो ऑनलाइन चैट करते हैं।"
5.  **लघु-संवाद**
    *   संचार के लिए प्रौद्योगिकी का उपयोग करने के बारे में बातचीत।

## 1. प्रौद्योगिकी शब्दावली

प्रौद्योगिकी और संचार से संबंधित आवश्यक शब्द सीखें।

| हिंदी                | इंडोनेशियाई    |
|----------------------|----------------|
| फोन                 | telepon        |
| कंप्यूटर             | komputer       |
| इंटरनेट              | internet       |
| ईमेल                | email          |
| सोशल मीडिया          | media sosial   |
| वेबसाइट              | situs web      |
| एप्लीकेशन (ऐप)      | aplikasi       |
| संदेश               | pesan          |
| भेजना               | mengirim       |
| प्राप्त करना         | menerima       |
| ब्राउज़ करना         | menjelajah     |
| टाइप करना            | mengetik       |
| फोन करना            | menelepon      |
| संदेश भेजना          | mengirim pesan |
| संवाद करना           | berkomunikasi  |

## 2. प्रौद्योगिकी उपयोग पर चर्चा

प्रौद्योगिकी का उपयोग कैसे करते हैं, इस बारे में बात करने के लिए इन संरचनाओं का उपयोग करें।

*   **उपयोग के बारे में बात करना:**
    *   `काम के लिए` (untuk pekerjaan)
    *   `संचार के लिए` (untuk komunikasi)
    *   `मनोरंजन के लिए` (untuk hiburan)

    *उदाहरण:*
    *   `मैं अपने कंप्यूटर का उपयोग काम के लिए करता हूँ।` (Saya menggunakan komputer saya untuk pekerjaan.)
    *   `वह संचार के लिए सोशल मीडिया का उपयोग करती है।` (Dia menggunakan media sosial untuk komunikasi.)

*   **आदतों के बारे में पूछना:**
    *   `क्या आप अक्सर इंटरनेट का उपयोग करते हैं?` (Apakah kamu sering menggunakan internet?)
    *   `आप अपने परिवार के साथ कैसे संवाद करते हैं?` (Bagaimana kamu berkomunikasi dengan keluargamu?)

## 3. संचार के बारे में सामान्य अभिव्यक्तियाँ

*   `मुझे फोन करो।` (Telepon saya.)
*   `मुझे टेक्स्ट करो।` (Kirim pesan kepada saya.)
*   `मुझे ईमेल करो।` (Email saya.)
*   `संपर्क में रहना।` (Tetap berhubungan.)

## 4. उपयोगी वाक्यांश

*   `मैं हर दिन अपने फोन का उपयोग करता हूँ।` (Saya menggunakan telepon saya setiap hari.)
*   `क्या आपके पास इंटरनेट तक पहुँच है?` (Apakah kamu punya akses internet?)
*   `मैं आपको एक ईमेल भेजूंगा।` (Saya akan mengirim email kepadamu.)
*   `चलो ऑनलाइन चैट करते हैं।` (Mari kita mengobrol daring.)

## 5. लघु-संवाद

**A:** `आप आमतौर पर अपने दोस्तों के साथ कैसे संवाद करते हैं?` (Bagaimana kamu biasanya berkomunikasi dengan teman-temanmu?)
**B:** `मैं आमतौर पर उन्हें टेक्स्ट करता हूँ या सोशल मीडिया ऐप का उपयोग करता हूँ।` (Saya biasanya mengirim pesan kepada mereka atau menggunakan aplikasi media sosial.)
**A:** `क्या आप अक्सर समाचार के लिए इंटरनेट का उपयोग करते हैं?` (Apakah kamu sering menggunakan internet untuk berita?)
**B:** `हाँ, मैं हर सुबह समाचार वेबसाइटें ब्राउज़ करता हूँ।` (Ya, saya menjelajah situs web berita setiap pagi.)

## अभ्यास

निम्नलिखित वाक्यों का इंडोनेशियाई में अनुवाद करें:

1.  मुझे अपना ईमेल जांचना है।
2.  उसने मुझे एक संदेश भेजा।
3.  यहां इंटरनेट बहुत तेज है।

**उत्तर कुंजी:**

1.  Saya perlu memeriksa email saya.
2.  Dia mengirimi saya pesan.
3.  Internet di sini sangat cepat.
