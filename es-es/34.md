## 2. Discutir el Uso de la Tecnología

Usa estas estructuras para hablar sobre cómo usas la tecnología.

*   **Hablar sobre el uso:**
    *   `para trabajar` (untuk pekerjaan)
    *   `para comunicación` (untuk komunikasi)
    *   `para entretenimiento` (untuk hiburan)

    *Ejemplos:*
    *   `Uso mi computadora para trabajar.` (Saya menggunakan komputer saya untuk pekerjaan.)
    *   `Ella usa las redes sociales para comunicarse.` (Dia menggunakan media sosial untuk komunikasi.)

*   **Preguntar sobre hábitos:**
    *   `¿Usas internet a menudo?` (Apakah kamu sering menggunakan internet?)
    *   `¿Cómo te comunicas con tu familia?` (Bagaimana kamu berkomunikasi dengan keluargamu?)

## 3. Expresiones Comunes sobre Comunicación

*   `Llámame.` (Telepon saya.)
*   `Envíame un mensaje.` (Kirim pesan kepada saya.)
*   `Envíame un correo electrónico.` (Email saya.)
*   `Mantente en contacto.` (Tetap berhubungan.)

## 4. Frases Útiles

*   `Uso mi teléfono todos los días.` (Saya menggunakan telepon saya setiap hari.)
*   `¿Tienes acceso a internet?` (Apakah kamu punya akses internet?)
*   `Te enviaré un correo electrónico.` (Saya akan mengirim email kepadamu.)
*   `Hablemos en línea.` (Mari kita mengobrol daring.)

## 5. Mini-Diálogo

**A:** `¿Cómo te comunicas normalmente con tus amigos?` (Bagaimana kamu biasanya berkomunikasi dengan teman-temanmu?)
**B:** `Normalmente les envío mensajes o uso aplicaciones de redes sociales.` (Saya biasanya mengirim pesan kepada mereka atau menggunakan aplikasi media sosial.)
**A:** `¿Sueles usar internet para las noticias?` (Apakah kamu sering menggunakan internet untuk berita?)
**B:** `Sí, navego por sitios web de noticias todas las mañanas.` (Ya, saya menjelajah situs web berita setiap pagi.)
