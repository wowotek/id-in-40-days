# Día 0 – Introducción

¡Bienvenido al curso de 40 días para dominar el indonesio! En este libro aprenderás paso a paso, cada día, de manera práctica y divertida.

---

## Cómo usar este libro
- Avanza una lección por día.
- Practica en voz alta los ejemplos y ejercicios.
- Si tienes dudas, únete a la comunidad para preguntar.
