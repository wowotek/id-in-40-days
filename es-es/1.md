# Día 1 – Presentaciones

Hoy aprenderás a presentarte en indonesio. ¡Es fácil presentarte usando frases sencillas!

---

## 🤝 Vocabulario para Presentaciones

| Indonesio | Español |
|-----------|------------------|
| nama      | nombre |
| saya      | yo |
| kamu      | tú/usted |
| dia       | él/ella |
| dari      | de (origen) |
| tinggal   | vivir |
| di        | en |
| apa       | qué |
| siapa     | quién |
| bagaimana | cómo |

---

## 🗣️ Frases para Presentarse

| Indonesio | Español |
|-----------------------------------|-----------------------------------|
| Nama saya Maria.                  | Mi nombre es María.               |
| Saya dari Spanyol.                | Soy de España.                    |
| Kamu siapa?                       | ¿Quién eres?                      |
| Dia tinggal di Bali.              | Él/Ella vive en Bali.             |
| Apa kabar?                        | ¿Cómo estás?                      |

---

## 🕵️ Diálogo de Ejemplo

**Al conocer a alguien nuevo:**

> **Tú:** Nama kamu siapa?
> 
> **Amigo:** Nama saya Luis. Kamu?
> 
> **Tú:** Nama saya Ana. Saya dari Spanyol.
> 
> **Amigo:** Selamat datang di Indonesia!

---

## 🧠 Práctica

Traduce al indonesio:

1. Mi nombre es Juan.
2. Soy de Indonesia.
3. ¿Quién es ella?
4. ¿Dónde vives?
5. Estoy bien.

✅ _Clave de Respuestas:_

1. Nama saya Juan.
2. Saya dari Indonesia.
3. Dia siapa?
4. Kamu tinggal di mana?
5. Baik.
