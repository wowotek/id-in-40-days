# Day 30: 취미와 여가 시간

## 서론
30일차 레슨에 오신 것을 환영합니다! 오늘은 취미와 여가 시간에 관련된 어휘와 표현을 배우겠습니다. 이를 통해 여러분의 관심사와 여가 시간에 무엇을 하는지 이야기할 수 있게 될 것입니다.

## 핵심 어휘

| 한국어 | 인도네시아어 |
|---|---|
| 취미 | hobi |
| 여가 | hobi/rekreasi |
| 여가 시간 | waktu luang |
| 읽다 | membaca |
| 쓰다 | menulis |
| 음악을 듣다 | mendengarkan musik |
| 영화를 보다 | menonton film |
| (게임/스포츠를) 하다 | bermain |
| 스포츠 | olahraga |
| 그리다 | menggambar |
| 색칠하다/그리다 | melukis |
| 요리하다 | memasak |
| 여행하다 | bepergian |
| 쇼핑하다 | berbelanja |
| 정원 가꾸기 | berkebun |
| 사진술 | fotografi |
| 수영하다 | berenang |
| 하이킹하다 | mendaki/hiking |
| 춤추다 | menari |
| 노래하다 | bernyanyi |

## 유용한 문구

*   **가장 좋아하는 취미는 무엇인가요?** (Apa hobi favoritmu?)
*   **저는 책 읽는 것을 좋아합니다.** (Saya suka membaca buku.)
*   **여가 시간에 무엇을 하시나요?** (Apa yang kamu lakukan di waktu luangmu?)
*   **저는 매일 운동을 합니다.** (Saya berolahraga setiap hari.)
*   **우리는 휴가 때 여행하는 것을 좋아합니다.** (Kami suka bepergian saat liburan.)
*   **그녀는 음악 듣는 것을 좋아합니다.** (Dia suka mendengarkan musik.)
*   **그들은 주말에 축구를 합니다.** (Mereka bermain sepak bola di akhir pekan.)
*   **주말에 계획이 있으신가요?** (Apakah kamu punya rencana untuk akhir pekan?)
*   **저는 그림 그리는 것을 배우고 싶습니다.** (Saya ingin belajar melukis.)
*   **요리는 저의 열정 중 하나입니다.** (Memasak adalah salah satu kesenangan saya.)

## 연습 문제

1.  **다음 문장을 인도네시아어로 번역하세요:**
    *   저는 사진 찍는 것을 정말 좋아해요.
    *   그는 수영을 잘해요.
    *   당신의 취미는 무엇인가요?

2.  **여가 시간에 가장 좋아하는 활동 세 가지를 한국어로 설명하세요.**

## 대화 예시

**A:** 안녕! 이번 주말에 뭐 해?
**B:** 안녕! 특별한 계획은 없어. 아마 책을 읽거나 음악을 들을 것 같아.
**A:** 아, 좋네! 나는 하이킹하는 것을 정말 좋아해. 너는 자연을 좋아하니?
**B:** 응, 많이! 하지만 나는 더 조용한 활동을 선호해. 예를 들어, 나는 그림 그리는 것을 좋아해.
**A:** 흥미롭네! 취미가 많구나!

## 결론
30일차 레슨을 완료하신 것을 축하드립니다! 이제 취미와 여가 시간에 대해 이야기할 수 있습니다. 이러한 표현들을 완벽하게 마스터하기 위해 계속 연습하세요.
