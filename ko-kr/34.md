## 2. Discussing Technology Use

Use these structures to talk about how you use technology.

*   **Talking about usage:**
    *   `업무용` (untuk pekerjaan)
    *   `소통용` (untuk komunikasi)
    *   `엔터테인먼트용` (untuk hiburan)

    *Examples:*
    *   `저는 업무용으로 컴퓨터를 사용합니다.` (Saya menggunakan komputer saya untuk pekerjaan.)
    *   `그녀는 소통용으로 소셜 미디어를 사용합니다.` (Dia menggunakan media sosial untuk komunikasi.)

*   **Asking about habits:**
    *   `인터넷을 자주 사용하시나요?` (Apakah kamu sering menggunakan internet?)
    *   `가족과 어떻게 소통하시나요?` (Bagaimana kamu berkomunikasi dengan keluargamu?)

## 3. Common Expressions about Communication

*   `전화하세요.` (Telepon saya.)
*   `문자 보내세요.` (Kirim pesan kepada saya.)
*   `이메일 보내세요.` (Email saya.)
*   `연락하고 지내요.` (Tetap berhubungan.)

## 4. Useful Phrases

*   `저는 매일 휴대폰을 사용합니다.` (Saya menggunakan telepon saya setiap hari.)
*   `인터넷 접속이 되나요?` (Apakah kamu punya akses internet?)
*   `이메일을 보내드리겠습니다.` (Saya akan mengirim email kepadamu.)
*   `온라인으로 채팅해요.` (Mari kita mengobrol daring.)

## 5. Mini-Dialogue

**A:** `친구들과 보통 어떻게 소통하시나요?` (Bagaimana kamu biasanya berkomunikasi dengan teman-temanmu?)
**B:** `저는 보통 문자를 보내거나 소셜 미디어 앱을 사용합니다.` (Saya biasanya mengirim pesan kepada mereka atau menggunakan aplikasi media sosial.)
**A:** `뉴스를 보기 위해 인터넷을 자주 사용하시나요?` (Apakah kamu sering menggunakan internet untuk berita?)
**B:** `네, 매일 아침 뉴스 웹사이트를 검색합니다.` (Ya, saya menjelajah situs web berita setiap pagi.)
