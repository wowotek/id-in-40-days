# Day 31: 직장 및 학교에 대해 이야기하기

## 서론
31일차 레슨에 오신 것을 환영합니다! 오늘은 직장과 학교에 관련된 어휘와 표현을 배우겠습니다. 이를 통해 여러분의 일상적인 직장 또는 학업 활동에 대해 이야기할 수 있게 될 것입니다.

## 핵심 어휘

| 한국어 | 인도네시아어 |
|---|---|
| 직장 | kerja |
| 직업 | pekerjaan |
| 회사 | perusahaan |
| 사무실 | kantor |
| 동료 | rekan kerja |
| 관리자 | manajer |
| 회의 | rapat |
| 프로젝트 | proyek |
| 학교 | sekolah |
| 대학교 | universitas |
| 학생 | siswa/mahasiswa |
| 선생님/교수님 | guru/dosen |
| 교실 | kelas |
| 수업 | pelajaran |
| 숙제 | pekerjaan rumah |
| 공부하다 | belajar |
| 시험 | ujian |
| 도서관 | perpustakaan |
| 휴식 | istirahat |
| 휴가 | liburan |

## 유용한 문구

*   **직업이 무엇입니까?** (Apa pekerjaanmu?)
*   **저는 회사에서 일합니다.** (Saya bekerja di perusahaan.)
*   **저는 학생입니다.** (Saya seorang siswa/mahasiswa.)
*   **어디서 공부하세요?** (Di mana kamu belajar?)
*   **내일 회의가 있습니다.** (Saya ada rapat besok.)
*   **제 일을 좋아합니다.** (Saya suka pekerjaan saya.)
*   **학교는 중요합니다.** (Sekolah itu penting.)
*   **숙제를 다 하셨나요?** (Apakah kamu sudah menyelesaikan pekerjaan rumahmu?)
*   **우리는 새로운 언어를 배우고 있습니다.** (Kami sedang belajar bahasa baru.)
*   **하루에 몇 시간 일하십니까?** (Berapa jam kamu bekerja sehari?)

## 연습 문제

1.  **다음 문장을 인도네시아어로 번역하세요:**
    *   저는 매일 대학교에 갑니다.
    *   제 상사는 매우 친절합니다.
    *   학교에서 가장 좋아하는 과목은 무엇입까요?

2.  **직장이나 학교에서의 일상생활을 한국어로 설명하세요.**

## 대화 예시

**A:** 안녕하세요! 대학교에서 무엇을 공부하세요?
**B:** 안녕하세요! 저는 경제학을 공부합니다. 당신은요? 일하세요?
**A:** 네, 저는 기술 회사에서 소프트웨어 엔지니어로 일합니다.
**B:** 흥미롭네요! 일을 좋아하세요?
**A:** 네, 아주 좋아합니다. 도전적이고 재미있습니다.

## 결론
31일차 레슨을 완료하신 것을 축하드립니다! 이제 직장과 학교에 대해 이야기할 수 있습니다. 이 표현들을 완벽하게 마스터하기 위해 계속 연습하세요.
