# День 1 – Знакомство

Сегодня вы научитесь представляться на индонезийском языке. Легко представляться, используя простые фразы!

---

## 🤝 Словарь для знакомства

| Индонезийский | Русский |
|---------------|------------------|
| nama          | имя              |
| saya          | я                |
| kamu          | ты/вы            |
| dia           | он/она           |
| dari          | из (происхождение)|
| tinggal       | жить             |
| di            | в/на             |
| apa           | что              |
| siapa         | кто              |
| bagaimana     | как              |

---

## 🗣️ Фразы для знакомства

| Индонезийский | Русский |
|-----------------------------------|-----------------------------------|
| Nama saya Aleksandr.              | Меня зовут Александр.             |
| Saya dari Rusia.                  | Я из России.                     |
| Kamu siapa?                       | Кто ты/вы?                       |
| Dia tinggal di Jakarta.           | Он/Она живет в Джакарте.          |
| Apa kabar?                        | Как дела?                         |

---

## 🕵️ Пример диалога

**При встрече с новым человеком:**

> **Вы:** Nama kamu siapa?
> 
> **Друг:** Nama saya Maria. Kamu?
> 
> **Вы:** Nama saya Oleg. Saya dari Rusia.
> 
> **Друг:** Selamat datang di Indonesia!

---

## 🧠 Практика

Переведите на индонезийский:

1. Меня зовут Елена.
2. Я из Индонезии.
3. Кто это он/она?
4. Где ты/вы живешь/живете?
5. Я хорошо.

✅ _Ответы:_

1. Nama saya Elena.
2. Saya dari Indonesia.
3. Dia siapa?
4. Kamu tinggal di mana?
5. Baik.
