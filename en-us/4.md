# Day 4 – Basic Sentence Structure

Now that you’ve learned personal pronouns, it’s time to start **building full sentences**.

Good news: **Indonesian sentence structure is simple and consistent**. Unlike many European languages, there are **no verb conjugations**, **no articles**, and **no gendered nouns**.

## 📐 Basic Sentence Pattern

The most common structure in Indonesian is:

- **Subject + Verb + Object**  
- (S + V + O)

This is the same as English.

## 🧱 Examples

| English                    | Indonesian             |
|----------------------------|------------------------|
| I eat rice.                | **Saya makan nasi.**   |
| You read a book.           | **Kamu baca buku.**    |
| He drinks water.           | **Dia minum air.**     |
| We study Indonesian.       | **Kita belajar bahasa Indonesia.** |
| They watch a movie.        | **Mereka nonton film.**|

> 📝 Verbs like *makan (eat)* and *minum (drink)* do **not** change with tense.

## ⏱ Tense in Indonesian

Indonesian does **not** have verb conjugations for past, present, or future.

Instead, use **time markers**:

| Time Marker | Meaning        | Example Sentence                  |
|-------------|----------------|-----------------------------------|
| **sudah**   | already (past) | Saya **sudah** makan. = I already ate. |
| **belum**   | not yet        | Kamu **belum** tidur? = You haven’t slept? |
| **sedang**  | currently      | Dia **sedang** belajar. = He/She is studying. |
| **akan**    | will           | Kami **akan** pergi. = We will go. |
| **tadi**    | earlier today  | Saya makan **tadi**. = I ate earlier. |
| **nanti**   | later          | Kita pergi **nanti**. = We’ll go later. |

## 🗣️ Sentence Practice

Build sentences using the structure:

- **Saya + [verb] + [object]**
- **Dia + [verb] + [object]**
- **Kita + akan + [verb] + [object]**

Examples:

1. Saya baca buku. – I read a book.  
2. Dia sudah makan. – He/She already ate.  
3. Kita akan belajar. – We will study.  
4. Mereka minum kopi. – They drink coffee.  
5. Kamu sedang tidur. – You are sleeping.

## ❗️Negative Sentences

To make a sentence negative:

| Word   | Use Case                     | Example                        |
|--------|------------------------------|--------------------------------|
| **tidak** | For verbs and adjectives     | Saya **tidak** makan. = I don’t eat. |
| **bukan** | For nouns or corrections     | Itu **bukan** buku saya. = That’s not my book. |
