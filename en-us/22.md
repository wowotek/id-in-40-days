# Day 22 — Making Requests and Offers

Today you'll learn how to politely ask for things and offer help in Indonesian. These skills are essential for smooth social interactions!

---

## 🙏 Request & Offer Vocabulary

| Indonesian         | English           |
|--------------------|-------------------|
| tolong             | please (request)  |
| boleh              | may/can           |
| bisa               | can               |
| mau                | want              |
| silakan            | please (offer)    |
| apakah             | (question marker) |
| bantu              | help              |
| menawarkan         | to offer          |

---

## 🗣️ Making Requests & Offers

| Indonesian                              | English                          |
|-----------------------------------------|----------------------------------|
| Tolong tutup pintu.                     | Please close the door.           |
| Bisa bantu saya?                        | Can you help me?                 |
| Boleh saya duduk di sini?               | May I sit here?                  |
| Mau minum apa?                          | What would you like to drink?    |
| Saya menawarkan bantuan.                | I offer my help.                 |
| Silakan masuk.                          | Please come in.                  |

---

## 🕵️ Example Dialogue

**Offering and requesting help:**

> **Anda:** Tolong, bisa bantu saya?
> 
> **Teman:** Tentu, ada apa?
> 
> **Anda:** Bisa tolong ambilkan air?
> 
> **Teman:** Silakan duduk, saya ambilkan.

---

## 🧠 Practice

Translate into Indonesian:

1. Please help me.
2. May I use this chair?
3. Can you close the window?
4. I offer my help.
5. Please come in.

✅ _Answer Key:_

1. Tolong bantu saya.
2. Boleh saya pakai kursi ini?
3. Bisa tutup jendela?
4. Saya menawarkan bantuan.
5. Silakan masuk.
