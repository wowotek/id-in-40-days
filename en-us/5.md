# Day 5 – Numbers (1–100)

Today you'll learn to count in **Indonesian** — a must for daily life: shopping, time, dates, and more.

Indonesian numbers are **regular and logical**, with almost no irregular forms. Once you learn the pattern, you can count as high as you want!

## 🔢 Numbers 1–10

| Number | Indonesian |
|--------|------------|
| 0      | nol |
| 1      | satu       |
| 2      | dua        |
| 3      | tiga       |
| 4      | empat      |
| 5      | lima       |
| 6      | enam       |
| 7      | tujuh      |
| 8      | delapan    |
| 9      | sembilan   |
| 10     | sepuluh    |

## 🔟 Teens (11–19)

| Number | Indonesian   | Notes                        |
|--------|--------------|------------------------------|
| 11     | sebelas      | special form (not "se-satu") |
| 12     | dua belas    | 2 + belas                    |
| 13     | tiga belas   | 3 + belas                    |
| ...    | ...          |                              |
| 19     | sembilan belas |                            |

> “Belas” is the suffix for the **-teen** numbers.

## 🧮 Tens (20, 30, ..., 90)

| Number | Indonesian     | Pattern                     |
|--------|----------------|-----------------------------|
| 20     | dua puluh      | 2 × 10                      |
| 30     | tiga puluh     | 3 × 10                      |
| 40     | empat puluh    | ...                         |
| 50     | lima puluh     |                             |
| 60     | enam puluh     |                             |
| 70     | tujuh puluh    |                             |
| 80     | delapan puluh  |                             |
| 90     | sembilan puluh |                             |

## 🧩 Building Numbers (21–99)

Use this pattern:

> **[Tens] + [Units]**

Examples:

- 21 = dua puluh satu  
- 35 = tiga puluh lima  
- 48 = empat puluh delapan  
- 99 = sembilan puluh sembilan  

## 💯 One Hundred

| Number | Indonesian |
|--------|------------|
| 100    | seratus    |
| 200    | dua ratus  |
| 300    | tiga ratus |
| 400    | empat ratus|

> “Se-” is a contraction of **satu**. So "seratus" = *one hundred*.  
> 200 = **dua ratus**, 300 = **tiga ratus**, and so on.

## 🎙️ Practice Reading

Say these aloud:

- Saya punya **dua belas** teman. → I have twelve friends.  
- Harganya **tiga puluh lima ribu rupiah**. → The price is 35,000 rupiah.  
- Nomor teleponnya **nol delapan satu tujuh...** → The phone number is 0817...
