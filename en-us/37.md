# Day 37 — Problems and Solutions

Today you'll learn how to talk about challenges, problems, and how to solve them in Indonesian. This is useful for real-life situations!

---

## 🛠️ Problems & Solutions Vocabulary

| Indonesian         | English           |
|--------------------|-------------------|
| masalah            | problem           |
| solusi             | solution          |
| kesulitan          | difficulty        |
| mudah              | easy              |
| sulit              | hard/difficult    |
| memperbaiki        | to fix/repair     |
| membantu           | to help           |
| saran              | advice/suggestion |
| mencoba            | to try            |
| berhasil           | succeed           |
| gagal              | fail              |

---

## 🗣️ Talking About Problems and Solutions

| Indonesian                              | English                          |
|-----------------------------------------|----------------------------------|
| Saya punya masalah dengan komputer.     | I have a problem with my computer.|
| Apa solusinya?                          | What is the solution?            |
| Bisa bantu saya?                        | Can you help me?                 |
| Saya mencoba memperbaiki sendiri.       | I try to fix it myself.          |
| Akhirnya, saya berhasil!                | Finally, I succeeded!            |

---

## 🕵️ Example Dialogue

**Solving a problem:**

> **Anda:** Komputer saya tidak menyala.
> 
> **Teman:** Sudah coba periksa kabelnya?
> 
> **Anda:** Sudah, tapi masih tidak bisa.
> 
> **Teman:** Mungkin perlu dibawa ke teknisi.

---

## 🧠 Practice

Translate into Indonesian:

1. I have a problem.
2. What is the solution?
3. This is difficult.
4. Can you help me?
5. I succeeded!

2. Apa solusinya?
