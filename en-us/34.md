# Day 34 — Technology and Communication

Today you'll learn how to talk about technology, gadgets, and staying in touch in Indonesian. This is useful for modern life!

---

## 💻 Technology & Communication Vocabulary

| Indonesian         | English           |
|--------------------|-------------------|
| telepon            | phone             |
| komputer           | computer          |
| internet           | internet          |
| email              | email             |
| pesan              | message           |
| aplikasi           | app/application   |
| media sosial       | social media      |
| mengirim           | to send           |
| menerima           | to receive        |
| panggilan          | call              |
| video call         | video call        |

---

## 🗣️ Talking About Technology

| Indonesian                              | English                          |
|-----------------------------------------|----------------------------------|
| Saya sering menggunakan internet.       | I often use the internet.        |
| Dia mengirim pesan lewat WhatsApp.      | He/She sends messages via WhatsApp. |
| Kami bertemu lewat video call.          | We meet via video call.          |
| Apakah kamu punya email?                | Do you have an email?            |
| Saya suka media sosial.                 | I like social media.             |

---

## 🕵️ Example Dialogue

**Talking about communication:**

> **Anda:** Bisa kirim foto lewat aplikasi ini?
> 
> **Teman:** Bisa, tinggal pilih dan kirim.
> 
> **Anda:** Terima kasih!

---

## 🧠 Practice

Translate into Indonesian:

1. I use a computer.
2. She likes social media.
3. We have a video call.
4. Do you have a phone?
5. He sends an email.

✅ _Answer Key:_

1. Saya menggunakan komputer.
2. Dia suka media sosial.
3. Kami video call.
4. Kamu punya telepon?
5. Dia mengirim email.
