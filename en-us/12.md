# 📦 Day 12 — Transport Vocabulary

Today we’ll cover common transportation vocabulary so you can confidently navigate, ride, and talk about getting around in Indonesia.

---

## 🚗 Basic Transport Words

| Indonesian | English         |
|------------|-----------------|
| mobil      | car             |
| motor      | motorcycle      |
| sepeda     | bicycle         |
| bus        | bus             |
| truk       | truck           |
| kereta     | train           |
| pesawat    | airplane        |
| kapal      | ship / boat     |
| becak      | pedicab / rickshaw |
| ojek       | motorcycle taxi |

> 📝 Note: In many cities, “ojek online” (e.g., Grab or Gojek) is the most common transport mode.

## 🧭 Useful Phrases

| Indonesian                           | English                         |
|--------------------------------------|----------------------------------|
| Di mana halte terdekat?              | Where is the nearest bus stop?  |
| Saya mau ke stasiun.                 | I want to go to the station.    |
| Berapa ongkosnya?                    | How much is the fare?           |
| Apakah ini ke bandara?               | Is this going to the airport?   |
| Tolong berhenti di depan ya.         | Please stop in front.           |

---

## 🛵 Special Transport Culture

In Indonesia, you’ll often hear:

- **Naik ojek** = ride a motorcycle taxi  
- **Go-jek / Grab** = popular transport apps  
- **Macet** = traffic jam

> 🔥 *Macet* is very common in big cities like Jakarta, so expect delays!

## 🚀 Practice

Translate these into Indonesian:

1. I want to take a bus.  
2. Where is the train station?  
3. How much is the motorcycle taxi?  
4. Please take me to the airport.  
5. Is there traffic now?

✅ _Answer Key:_
1. Saya mau naik bus.  
2. Di mana stasiun kereta?  
3. Berapa ongkos ojek?  
4. Tolong antar saya ke bandara.  
5. Apakah sekarang macet?
