# Day 38 — Giving Opinions and Advice

Today you'll learn how to share your opinions and give advice in Indonesian. This is important for discussions and helping others!

---

## 💬 Opinions & Advice Vocabulary

| Indonesian         | English           |
|--------------------|-------------------|
| menurut saya       | in my opinion     |
| saya pikir         | I think           |
| sebaiknya          | should            |
| lebih baik         | better            |
| saran              | suggestion        |
| pendapat           | opinion           |
| setuju             | agree             |
| tidak setuju       | disagree          |
| penting            | important         |
| perlu              | necessary         |

---

## 🗣️ Giving Opinions and Advice

| Indonesian                              | English                          |
|-----------------------------------------|----------------------------------|
| Menurut saya, ini ide bagus.            | In my opinion, this is a good idea.|
| Saya pikir kamu harus belajar lebih giat.| I think you should study harder.  |
| Sebaiknya kita pergi sekarang.           | We should go now.                |
| Saya setuju dengan pendapatmu.           | I agree with your opinion.        |
| Lebih baik kamu istirahat.               | You better rest.                 |

---

## 🕵️ Example Dialogue

**Giving advice:**

> **Anda:** Saya bingung memilih jurusan kuliah.
> 
> **Teman:** Menurut saya, pilih yang kamu suka.
> 
> **Anda:** Terima kasih atas sarannya!

---

## 🧠 Practice

Translate into Indonesian:

1. In my opinion, this is good.
2. I think you should try.
3. You better go home.
4. I agree with you.
5. This is important.

✅ _Answer Key:_

1. Menurut saya, ini bagus.
2. Saya pikir kamu harus mencoba.
3. Lebih baik kamu pulang.
4. Saya setuju dengan kamu.
5. Ini penting.
