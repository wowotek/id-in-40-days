# Day 26 — Eating Out

Today you'll learn how to order food and drinks at restaurants in Indonesian. Enjoy dining out with confidence!

---

## 🍽️ Eating Out Vocabulary

| Indonesian         | English           |
|--------------------|-------------------|
| restoran           | restaurant        |
| rumah makan        | eatery            |
| menu               | menu              |
| pesan              | to order          |
| makanan            | food              |
| minuman            | drink             |
| pelayan            | waiter/waitress   |
| meja               | table             |
| bayar              | to pay            |
| tagihan            | bill              |

---

## 🗣️ Ordering Food and Drinks

| Indonesian                              | English                          |
|-----------------------------------------|----------------------------------|
| Saya mau pesan nasi goreng.             | I want to order fried rice.      |
| Ada menu minuman?                       | Is there a drink menu?           |
| Tolong satu meja untuk dua orang.       | A table for two, please.         |
| Pelayan, minta tagihan.                 | Waiter, the bill please.         |
| Apa rekomendasi makanan di sini?        | What is the recommended food here?|

---

## 🕵️ Example Dialogue

**At a restaurant:**

> **Anda:** Ada meja kosong?
> 
> **Pelayan:** Ada, silakan duduk.
> 
> **Anda:** Saya mau pesan ayam bakar dan es teh.
> 
> **Pelayan:** Baik, tunggu sebentar.

---

## 🧠 Practice

Translate into Indonesian:

1. I want to order coffee.
2. Is there a menu?
3. The bill, please.
4. A table for three, please.
5. What is the recommended drink?

✅ _Answer Key:_

1. Saya mau pesan kopi.
2. Ada menu?
3. Tagihannya, tolong.
4. Satu meja untuk tiga orang, tolong.
5. Apa minuman rekomendasi di sini?
