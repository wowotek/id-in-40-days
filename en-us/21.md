# Day 21 — Expressing Likes and Dislikes

Today you'll learn how to talk about your preferences in Indonesian. This is essential for daily conversations!

---

## ❤️ Preference Vocabulary

| Indonesian     | English         |
|----------------|----------------|
| suka           | like            |
| tidak suka     | don't like      |
| cinta          | love            |
| benci          | hate            |
| favorit        | favorite        |
| lebih suka     | prefer          |
| hobi           | hobby           |

---

## 🗣️ Talking About Preferences

| Indonesian                        | English                        |
|-----------------------------------|--------------------------------|
| Saya suka kopi.                   | I like coffee.                 |
| Dia tidak suka durian.            | He/She doesn't like durian.    |
| Kami cinta musik.                 | We love music.                 |
| Mereka benci hujan.               | They hate rain.                |
| Apa makanan favoritmu?            | What's your favorite food?     |
| Saya lebih suka teh daripada kopi.| I prefer tea to coffee.        |

---

## 🕵️ Example Dialogue

**Talking about hobbies:**

> **Anda:** Apa hobi kamu?
> 
> **Teman:** Saya suka membaca buku.
> 
> **Anda:** Saya lebih suka menonton film.
> 
> **Teman:** Makanan favoritmu apa?
> 
> **Anda:** Saya suka sate ayam!

---

## 🧠 Practice

Translate into Indonesian:

1. I like music.
2. She doesn't like coffee.
3. We love reading books.
4. What is your favorite drink?
5. I prefer tea.

✅ _Answer Key:_

1. Saya suka musik.
2. Dia tidak suka kopi.
3. Kami cinta membaca buku.
4. Minuman favoritmu apa?
5. Saya lebih suka teh.
