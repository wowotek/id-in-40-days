# Day 28 — Weather and Seasons

Today you'll learn how to talk about the weather and seasons in Indonesian. This is great for daily conversations and travel!

---

## ☀️ Weather & Season Vocabulary

| Indonesian         | English           |
|--------------------|-------------------|
| cuaca              | weather           |
| musim              | season            |
| panas              | hot               |
| dingin             | cold              |
| hujan              | rain              |
| cerah              | sunny/clear       |
| berawan            | cloudy            |
| angin              | wind              |
| badai              | storm             |
| lembab             | humid             |
| kemarau            | dry season        |
| hujan (musim)      | rainy season      |

---

## 🗣️ Talking About Weather

| Indonesian                              | English                          |
|-----------------------------------------|----------------------------------|
| Cuaca hari ini cerah.                   | The weather is clear today.      |
| Sekarang musim hujan.                   | It's the rainy season now.       |
| Besok akan panas.                       | It will be hot tomorrow.         |
| Angin bertiup kencang.                  | The wind is blowing hard.        |
| Saya suka musim kemarau.                | I like the dry season.           |

---

## 🕵️ Example Dialogue

**Talking about the weather:**

> **Anda:** Cuaca hari ini bagaimana?
> 
> **Teman:** Cerah dan tidak hujan.
> 
> **Anda:** Saya suka musim seperti ini.

---

## 🧠 Practice

Translate into Indonesian:

1. The weather is rainy.
2. It is hot today.
3. I like the rainy season.
4. Tomorrow will be cold.
5. The wind is strong.

✅ _Answer Key:_

1. Cuacanya hujan.
2. Hari ini panas.
3. Saya suka musim hujan.
4. Besok akan dingin.
5. Anginnya kencang.
