# Day 35 — Nature and the Environment

Today you'll learn how to talk about nature, the environment, and the world around you in Indonesian. This is great for outdoor conversations and environmental awareness!

---

## 🌳 Nature & Environment Vocabulary

| Indonesian         | English           |
|--------------------|-------------------|
| alam               | nature            |
| lingkungan         | environment       |
| pohon              | tree              |
| sungai             | river             |
| gunung             | mountain          |
| laut               | sea/ocean         |
| hutan              | forest            |
| bunga              | flower            |
| hewan              | animal            |
| sampah             | trash/garbage     |
| bersih             | clean             |
| kotor              | dirty             |

---

## 🗣️ Talking About Nature

| Indonesian                              | English                          |
|-----------------------------------------|----------------------------------|
| Saya suka berjalan di hutan.            | I like walking in the forest.    |
| Sungai ini sangat bersih.               | This river is very clean.        |
| Ada banyak bunga di taman.              | There are many flowers in the park. |
| Kita harus menjaga lingkungan.          | We must protect the environment. |
| Gunung itu tinggi sekali.               | That mountain is very tall.      |

---

## 🕵️ Example Dialogue

**Talking about the environment:**

> **Anda:** Kamu suka alam?
> 
> **Teman:** Ya, saya suka pergi ke gunung dan laut.
> 
> **Anda:** Kita harus menjaga kebersihan, ya!
> 
> **Teman:** Betul, jangan buang sampah sembarangan.

---

## 🧠 Practice

Translate into Indonesian:

1. The sea is beautiful.
2. There are many animals in the forest.
3. This park is clean.
4. We must not litter.
5. That tree is big.

✅ _Answer Key:_

1. Laut itu indah.
2. Ada banyak hewan di hutan.
3. Taman ini bersih.
4. Kita tidak boleh buang sampah.
5. Pohon itu besar.
