# 🏥 Day 17 — Health & Body

Today you'll learn how to talk about your health, body parts, and common symptoms in Indonesian. Useful for doctor visits or just describing how you feel!

---

## 🧑‍⚕️ Health & Body Vocabulary

| Indonesian     | English         |
|----------------|----------------|
| badan          | body           |
| kepala         | head           |
| mata           | eye            |
| telinga        | ear            |
| hidung         | nose           |
| mulut          | mouth          |
| tangan         | hand/arm       |
| kaki           | foot/leg       |
| perut          | stomach        |
| sakit          | sick/pain      |
| demam          | fever          |
| batuk          | cough          |
| pilek          | cold (illness) |
| luka           | wound/injury   |
| sehat          | healthy        |
| dokter         | doctor         |
| obat           | medicine       |

---

## 🩺 Talking About Health

| Indonesian                        | English                        |
|-----------------------------------|--------------------------------|
| Saya sakit kepala.                | I have a headache.             |
| Perut saya sakit.                 | My stomach hurts.              |
| Saya demam.                       | I have a fever.                |
| Saya mau ke dokter.               | I want to see a doctor.        |
| Sudah minum obat?                 | Have you taken medicine?       |
| Saya merasa sehat.                | I feel healthy.                |

---

## 👩‍⚕️ Example Dialogue

**At the clinic:**

> **Dokter:** Ada keluhan apa?
> 
> **Anda:** Saya batuk dan pilek sejak kemarin.
> 
> **Dokter:** Sudah minum obat?
> 
> **Anda:** Sudah, tapi belum sembuh.
> 
> **Dokter:** Nanti saya beri resep, ya.

---

## 🧠 Practice

Translate into Indonesian:

1. My head hurts.
2. I have a fever.
3. I want to see a doctor.
4. Have you taken medicine?
5. I feel healthy.

✅ _Answer Key:_

1. Kepala saya sakit.
2. Saya demam.
3. Saya mau ke dokter.
4. Sudah minum obat?
5. Saya merasa sehat.
