# 第2天 – 问候与基础表达

今天你将学习印尼语的问候语和基本表达。这些短语在日常对话中非常有用！

---

## 👋 问候与基础表达词汇

| 印尼语 | 中文 |
|--------|------------------|
| selamat pagi | 早上好 |
| selamat siang| 中午好 (上午) |
| selamat sore | 下午好 (下午) |
| selamat malam| 晚上好 |
| terima kasih | 谢谢 |
| sama-sama    | 不客气 |
| maaf         | 对不起/不好意思 |
| permisi      | 不好意思 (引起注意) |
| ya           | 是的 |
| tidak        | 不是 |
| oke          | 好的 |

---

## 🗣️ 基本表达

| 印尼语 | 中文 |
|-----------------------------------|----------------------------|
| Selamat pagi, Bapak.              | 先生，早上好。 |
| Terima kasih banyak.              | 非常感谢。 |
| Maaf, saya tidak mengerti.        | 对不起，我不明白。 |
| Permisi, toiletnya di mana?       | 不好意思，厕所在哪里？ |
| Ya, saya mengerti.                | 是的，我明白了。 |

---

## 🕵️ 对话示例

**在餐厅：**

> **你：** Permisi, bisa bantu?
> 
> **服务员：** Ya, ada apa?
> 
> **你：** Terima kasih banyak.
> 
> **服务员：** Sama-sama.

---

## 🧠 练习

翻译成印尼语：

1. 晚上好。
2. 不客气。
3. 对不起。
4. 是的。
5. 不，谢谢。

✅ _答案:_

1. Selamat malam.
2. Sama-sama.
3. Maaf.
4. Ya.
5. Tidak, terima kasih.
