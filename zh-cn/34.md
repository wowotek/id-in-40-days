## 2. 讨论科技使用

使用这些结构来谈论你如何使用科技。

*   **谈论使用方式：**
    *   `用于工作` (untuk pekerjaan)
    *   `用于通讯` (untuk komunikasi)
    *   `用于娱乐` (untuk hiburan)

    *示例:*
    *   `我用电脑工作。` (Saya menggunakan komputer saya untuk pekerjaan.)
    *   `她用社交媒体通讯。` (Dia menggunakan media sosial untuk komunikasi.)

*   **询问习惯：**
    *   `你经常使用互联网吗？` (Apakah kamu sering menggunakan internet?)
    *   `你如何与家人通讯？` (Bagaimana kamu berkomunikasi dengan keluargamu?)

## 3. 常见通讯表达

*   `给我打电话。` (Telepon saya.)
*   `给我发短信。` (Kirim pesan kepada saya.)
*   `给我发电子邮件。` (Email saya.)
*   `保持联系。` (Tetap berhubungan.)

## 4. 有用短语

*   `我每天都用手机。` (Saya menggunakan telepon saya setiap hari.)
*   `你有互联网接入吗？` (Apakah kamu punya akses internet?)
*   `我将给你发送一封电子邮件。` (Saya akan mengirim email kepadamu.)
*   `我们在线聊天吧。` (Mari kita mengobrol daring.)

## 5. 迷你对话

**A:** `你通常如何与朋友通讯？` (Bagaimana kamu biasanya berkomunikasi dengan teman-temanmu?)
**B:** `我通常给他们发短信或使用社交媒体应用程序。` (Saya biasanya mengirim pesan kepada mereka atau menggunakan aplikasi media sosial.)
**A:** `你经常使用互联网看新闻吗？` (Apakah kamu sering menggunakan internet untuk berita?)
**B:** `是的，我每天早上都浏览新闻网站。` (Ya, saya menjelajah situs web berita setiap pagi.)

## 练习

将以下句子翻译成印度尼西亚语：

1.  我需要检查我的电子邮件。
2.  她给我发了一条消息。
3.  这里的互联网非常快。

**答案：**

1.  Saya perlu memeriksa email saya.
2.  Dia mengirimi saya pesan.
3.  Internet di sini sangat cepat.
