# 第1天 – 自我介绍

今天你将学习如何用印尼语介绍自己。用简单的短语来介绍自己吧！

---

## 🤝 自我介绍词汇

| 印尼语 | 中文 |
|--------|----------|
| nama   | 名字 |
| saya   | 我 |
| kamu   | 你 |
| dia    | 他/她 |
| dari   | 来自 |
| tinggal| 居住 |
| di     | 在 |
| apa    | 什么 |
| siapa  | 谁 |
| bagaimana | 怎么样 |

---

## 🗣️ 自我介绍短语

| 印尼语 | 中文 |
|-----------------------------------|----------------------------|
| Nama saya Lina.                   | 我的名字是丽娜。 |
| Saya dari Tiongkok.               | 我来自中国。 |
| Kamu siapa?                       | 你是谁？ |
| Dia tinggal di Bali.              | 他/她住在巴厘岛。 |
| Apa kabar?                        | 你好吗？ |

---

## 🕵️ 对话示例

**认识新朋友时：**

> **你：** Nama kamu siapa?
> 
> **朋友：** Nama saya Budi. Kamu?
> 
> **你：** Nama saya Mei. Saya dari Tiongkok.
> 
> **朋友：** Selamat datang di Indonesia!

---

## 🧠 练习

翻译成印尼语：

1. 我的名字是张。
2. 我来自印度尼西亚。
3. 他是谁？
4. 你住在哪里？
5. 我很好。

✅ _答案:_

1. Nama saya Zhang.
2. Saya dari Indonesia.
3. Dia siapa?
4. Kamu tinggal di mana?
5. Baik.
