# Day 22 – 依頼と提案

今日はインドネシア語で依頼したり、提案したりする方法を学びます。これはスムーズなコミュニケーションに役立ちます！

---

## 🙏 依頼と提案の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| bisa          | できる/可能である |
| tolong         | お願い/助けて |
| mau            | ～したい/～が欲しい |
| ayo            | ～しよう/さあ |
| bagaimana kalau| ～するのはどうですか |
| mungkin        | もしかしたら |
| pinjam         | 借りる |
| antar          | 送る |
| bantu          | 助ける |
| pergi          | 行く |

---

## 🗣️ 依頼と提案の表現

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Bisakah kamu tolong saya?         | 手伝ってくれますか？ |
| Saya mau minum kopi.              | 私はコーヒーが飲みたいです。 |
| Ayo pergi ke pantai!              | ビーチに行こう！ |
| Bagaimana kalau kita makan malam bersama? | 一緒に夕食を食べるのはどうですか？ |
| Mungkin kita bisa pergi besok.    | もしかしたら明日行けるかもしれません。 |

---

## 🕵️ 会話例

**友達に助けを求める:**

> **Anda:** Tolong, saya butuh bantuan.
> 
> **Teman:** Ada apa? Bisakah saya bantu?
> 
> **Anda:** Bisakah kamu pinjamkan saya uang?
> 
> **Teman:** Tentu saja. Berapa?

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私は水が欲しいです。
2. 映画を見に行こう！
3. あなたは私を送ることができますか？
4. 彼らは泳ぎたいですか？
5. 週末に図書館に行くのはどうですか？

✅ _解答キー:_

1. Saya mau air.
2. Ayo pergi menonton film!
3. Bisakah kamu antar saya?
4. Mereka mau berenang?
5. Bagaimana kalau kita pergi ke perpustakaan di akhir pekan?
