# Day 15 – 問題と解決策

今日はインドネシア語で問題について話したり、解決策を提案したりする方法を学びます。これは困難な状況で役立ちます！

---

## ⚠️ 問題と解決策の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| masalah        | 問題 |
| solusi         | 解決策 |
| sulit          | 難しい |
| mudah          | 簡単な |
| bantu          | 助ける |
| mencari        | 探す |
| menemukan      | 見つける |
| jangan khawatir| 心配しないで |
| ada apa?       | どうしたの？ |
| perlu          | 必要とする |

---

## 🗣️ 問題と解決策について話す

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Saya punya masalah besar.         | 私は大きな問題を抱えています。 |
| Apa solusinya?                    | 解決策は何ですか？ |
| Ini sangat sulit.                 | これはとても難しいです。 |
| Bisakah kamu bantu saya?          | 手伝ってくれますか？ |
| Jangan khawatir, kita akan menemukan solusi. | 心配しないで、解決策を見つけます。 |

---

## 🕵️ 会話例

**問題を解決する:**

> **Anda:** Aduh, saya lupa dompet saya.
> 
> **Teman:** Oh, itu masalah. Tapi jangan khawatir, saya bisa bantu.
> 
> **Anda:** Benarkah? Terima kasih banyak!
> 
> **Teman:** Sama-sama. Kita bisa pinjam uang dulu.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私は解決策を探しています。
2. これは簡単ではありません。
3. 助けが必要です。
4. 心配しないでください。
5. あなたの解決策は何ですか？

✅ _解答キー:_

1. Saya mencari solusi.
2. Ini tidak mudah.
3. Saya perlu bantuan.
4. Jangan khawatir.
5. Apa solusi kamu?
