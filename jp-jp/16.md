# Day 16 – 意見とアドバイス

今日はインドネシア語で意見を述べたり、アドバイスをしたりする方法を学びます。これは会話をより豊かにするのに役立ちます！

---

## 👍 意見とアドバイスの語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| menurut saya   | 私の意見では |
| pikir          | 考える |
| saran          | アドバイス |
| harus          | ～すべき |
| baik           | 良い |
| buruk          | 悪い |
| setuju         | 同意する |
| tidak setuju   | 同意しない |
| penting        | 大切な/重要な |
| mungkin        | たぶん/もしかしたら |

---

## 🗣️ 意見とアドバイスを表現する

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Menurut saya, ini ide yang bagus. | 私の意見では、これは良い考えです。 |
| Kamu harus belajar lebih giat.    | あなたはもっと一生懸命勉強すべきです。 |
| Saya tidak setuju dengan kamu.    | 私はあなたに同意しません。 |
| Ini penting untuk masa depan.     | これは将来のために重要です。 |
| Mungkin kita bisa coba lagi.      | もしかしたらもう一度試せるかもしれません。 |

---

## 🕵️ 会話例

**意見を交換する:**

> **Anda:** Bagaimana pendapatmu tentang film ini?
> 
> **Teman:** Menurut saya, filmnya bagus sekali. Tapi ceritanya agak lambat.
> 
> **Anda:** Saya setuju. Tapi aktornya hebat.
> 
> **Teman:** Ya, itu benar.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私はそう思います。
2. あなたは医者に行くべきです。
3. これは悪い考えです。
4. 彼は同意しません。
5. たぶん、明日雨が降るでしょう。

✅ _解答キー:_

1. Saya pikir begitu.
2. Kamu harus pergi ke dokter.
3. Ini ide yang buruk.
4. Dia tidak setuju.
5. Mungkin besok hujan.
