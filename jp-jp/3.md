# Day 3 – 数字と時間

今日はインドネシア語で数を数えたり時間を言ったりする方法を学びます。これらのスキルは日常生活で非常に役立ちます！

---

## 🔢 数字の語彙

| インドネシア語 | 日本語 |
|----------------|----------|
| nol            | ゼロ     |
| satu           | 一       |
| dua            | 二       |
| tiga           | 三       |
| empat          | 四       |
| lima           | 五       |
| enam           | 六       |
| tujuh          | 七       |
| delapan        | 八       |
| sembilan       | 九       |
| sepuluh        | 十       |
| sebelas        | 十一     |
| dua belas      | 十二     |
| dua puluh      | 二十     |
| seratus        | 百       |
| seribu         | 千       |

---

## ⏰ 時間の表現

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Jam berapa sekarang?              | 今何時ですか？ |
| Jam satu.                         | 1時です。 |
| Jam dua belas siang.              | 正午12時です。 |
| Jam tujuh malam.                  | 午後7時です。 |
| Pukul tiga sore.                  | 午後3時です。 |
| Setengah jam.                     | 30分。 |
| Lima belas menit.                 | 15分。 |

---

## 🕵️ 会話例

**時間について尋ねる:**

> **Anda:** Jam berapa sekarang?
>
> **Teman:** Jam delapan pagi.
> 
> **Anda:** Terima kasih.
> 
> **Teman:** Sama-sama.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 5時です。
2. 25分。
3. 9時です。
4. 今何時ですか？
5. 100です。

✅ _解答キー:_

1. Jam lima.
2. Dua puluh lima menit.
3. Jam sembilan.
4. Jam berapa sekarang?
5. Seratus.
