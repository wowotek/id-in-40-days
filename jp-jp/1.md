# Day 1 - アルファベット と 発音

インドネシア語のアルファベットは、ラテンアルファベットを使用しており、
26文字から成っているため、学ぶのが簡単です。
インドネシア語のアルファベットは、インドネシア語の発音システムにも使用されています。
インドネシア語は音韻的なアルファベットを使用しており、各文字は特定の音を表しています。
また、文字の音は単語の中で現れる場所に関係なく一貫しています。

### インドネシア語では子音で終わる単語が多い
#### 日本語とのちがい
日本語の単語は、ほとんどが**母音（あ、い、う、え、お）**で終わります。例外は「ん」だけです。

- 例：
  - さくら（aで終わる）
  - たべる（uで終わる）
  - ほん（んで終わる）

#### インドネシア語では？
インドネシア語では 子音で終わる単語 がとても多く存在します。
たとえば、「k」「n」「m」「t」「s」などで終わる単語は非常によく使われます。

- 例：
  - makan（食べる）
  - hitam（黒）
  - cepat（早い）

日本語にはない発音の終わり方なので、最初は少し難しく感じるかもしれませんが、慣れればすぐに自然になります。


### インドネシア語の特別なつづりと発音
- ng の発音　「ン」
  - 発音：日本語の「ん」がつながったような音です。ただし、語の先頭にくる場合、日本語にはない音なので注意が必要です。
  - 例：
    - ngantuk（ングァントゥック）＝ 眠い
    - bangun（バンウン）＝ 起きる
    - manga (マンア) = 漫画

  「ng」は語の終わりや途中にもよく出てきます。
- ngg の発音　「ング」
  - 例：
    - nggak (エンガクッ) ＝ いいえ
    - bangga （バンガ）＝ 誇り
    - mangga （マンガ）＝ (果物の)マンゴー
- ny の発音（「ニャ」）
  - 発音：日本語の「にゃ」「にゅ」「にょ」のような音です。
  - 例：
    - nyanyi（ニャニィ）＝歌う
    - banyak（バニャックッ）＝たくさん
- sy の発音（「シャ」）
  - 発音：日本語の「しゃ」「しゅ」「しょ」のような音です。アラビア語由来の単語によく見られます。
  - 例：
    - syukur（シュクル）＝感謝
    - syarat（シャラットッ）＝条件
- kh の発音（「ハ」より強い音）
  - 発音：喉の奥から出す「ハーッ」という音。アラビア語由来の言葉によく使われます。日本語にはない音です。
  - 例：
    - khalifah（ハリファ）＝カリフ（イスラム指導者）
    - akhir（アヒル）＝終わり、最後
