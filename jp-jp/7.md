# Day 7 – ショッピング

今日はインドネシア語で買い物をする方法を学びます。これは市場やお店で役立ちます！

---

## 🛍️ ショッピングの語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| belanja        | 買い物をする |
| toko           | 店/ショップ |
| pasar          | 市場 |
| harga          | 価格 |
| berapa         | いくつ/いくら |
| mahal          | 高い |
| murah          | 安い |
| beli           | 買う |
| jual           | 売る |
| uang           | お金 |
| rupiah         | ルピア (インドネシアの通貨) |

---

## 🗣️ ショッピングの表現

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Saya mau belanja di pasar.        | 私は市場で買い物がしたいです。 |
| Berapa harganya?                  | いくらですか？ |
| Ini mahal sekali.                 | これはとても高いです。 |
| Ada yang lebih murah?             | もっと安いものはありますか？ |
| Saya mau beli ini.                | 私はこれを買いたいです。 |

---

## 🕵️ 会話例

**市場で交渉する:**

> **Anda:** Berapa harganya jeruk ini?
> 
> **Penjual:** Ini lima belas ribu rupiah.
> 
> **Anda:** Aduh, mahal. Bisa kurang?
> 
> **Penjual:** Oke, dua belas ribu saja.
> 
> **Anda:** Baik, saya beli.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. このシャツはいくらですか？
2. 安いですか？
3. 私は水を買いたいです。
4. 私は市場に行きます。
5. 彼女は売っています。

✅ _解答キー:_

1. Berapa harga kemeja ini?
2. Murah?
3. Saya mau beli air.
4. Saya pergi ke pasar.
5. Dia jual.
