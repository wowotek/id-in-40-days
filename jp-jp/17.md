# Day 17 – 物語と経験

今日はインドネシア語で物語や経験を共有する方法を学びます。これは会話をより面白くするのに役立ちます！

---

## 📖 物語と経験の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| cerita         | 物語/話 |
| pengalaman     | 経験 |
| dulu           | 昔/以前 |
| sekarang       | 今/現在 |
| lalu           | それから/そして |
| bahagia        | 幸せな |
| sedih          | 悲しい |
| lucu           | 面白い |
| menarik        | 興味深い |
| tak terlupakan | 忘れられない |

---

## 🗣️ 物語と経験を話す

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Saya punya cerita lucu.           | 私は面白い話があります。 |
| Ini pengalaman pertama saya.      | これは私の初めての経験です。 |
| Dulu saya tinggal di desa.        | 昔、私は村に住んでいました。 |
| Lalu, saya pergi ke kota.         | それから、私は町に行きました。 |
| Pengalaman itu sangat tak terlupakan. | その経験はとても忘れられません。 |

---

## 🕵️ 会話例

**経験について話す:**

> **Anda:** Kamu punya pengalaman menarik?
> 
> **Teman:** Ya, saya pernah jalan-jalan ke gunung Rinjani. Sangat indah!
> 
> **Anda:** Wah, itu pasti pengalaman yang tak terlupakan.
> 
> **Teman:** Tentu saja. Saya senang sekali.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私は悲しい話があります。
2. これは私の新しい経験です。
3. 彼は今ここにいます。
4. それは面白い物語です。
5. 彼女の経験は興味深いです。

✅ _解答キー:_

1. Saya punya cerita sedih.
2. Ini pengalaman baru saya.
3. Dia ada di sini sekarang.
4. Itu cerita yang lucu.
5. Pengalamannya menarik.
