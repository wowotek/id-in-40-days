# Day 11 – 健康

今日はインドネシア語で健康について話す方法を学びます。これは体調を伝えたり、助けを求めたりするのに役立ちます！

---

## 🏥 健康の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| sehat          | 健康な/元気な |
| sakit          | 病気の/痛い |
| pusing         | 頭痛/めまい |
| demam          | 熱 |
| batuk          | 咳 |
| pilek          | 鼻水/風邪 |
| lelah          | 疲れた |
| dokter         | 医者 |
| obat           | 薬 |
| rumah sakit    | 病院 |

---

## 🗣️ 健康について話す

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Saya merasa tidak enak badan.     | 私は気分が良くありません。 |
| Dia sakit kepala.                 | 彼/彼女は頭が痛いです。 |
| Kamu harus minum obat.            | あなたは薬を飲むべきです。 |
| Saya butuh ke dokter.             | 私は医者に行く必要があります。 |
| Dia demam tinggi.                 | 彼/彼女は高熱があります。 |

---

## 🕵️ 会話例

**体調を尋ねる・伝える:**

> **Anda:** Ada apa? Kamu kelihatan lelah.
> 
> **Teman:** Ya, saya sedikit pusing dan batuk.
> 
> **Anda:** Kamu sudah minum obat?
> 
> **Teman:** Belum. Saya mau tidur dulu.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私は病気です。
2. 彼は熱があります。
3. 私は医者が必要です。
4. 彼女は疲れています。
5. あなたは元気ですか？

✅ _解答キー:_

1. Saya sakit.
2. Dia demam.
3. Saya butuh dokter.
4. Dia lelah.
5. Kamu sehat?
