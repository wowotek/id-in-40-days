# Day 9 – 交通手段

今日はインドネシア語で交通手段について話す方法を学びます。これは旅行計画に役立ちます！

---

## 🚗 交通手段の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| mobil          | 車 |
| motor          | バイク/オートバイ |
| taksi          | タクシー |
| bus            | バス |
| kereta         | 電車 |
| pesawat        | 飛行機 |
| perahu         | 船 |
| jalan kaki     | 徒歩 |
| naik           | 乗る (交通手段) |
| pergi dengan   | 〜で行く |

---

## 🗣️ 交通手段について話す

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Saya pergi ke kantor naik mobil.  | 私は車でオフィスに行きます。 |
| Dia naik bus setiap hari.         | 彼/彼女は毎日バスに乗ります。 |
| Kami mau naik taksi ke bandara.   | 私たちはタクシーで空港に行きたいです。 |
| Mereka pergi dengan kereta.       | 彼らは電車で行きます。 |
| Kamu suka naik motor?             | あなたはバイクに乗るのが好きですか？ |

---

## 🕵️ 会話例

**どこかへ行く方法について話す:**

> **Anda:** Kamu pergi ke Bali naik apa?
> 
> **Teman:** Saya pergi naik pesawat.
> 
> **Anda:** Oh, cepat ya.
> 
> **Teman:** Ya, kalau tidak macet.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私は電車で学校に行きます。
2. 彼は車を持っています。
3. 私たちは歩いて市場に行きます。
4. あなたは飛行機で行きますか？
5. 彼女はタクシーを乗りたいです。

✅ _解答キー:_

1. Saya pergi ke sekolah naik kereta.
2. Dia punya mobil.
3. Kami pergi ke pasar jalan kaki.
4. Kamu pergi naik pesawat?
5. Dia mau naik taksi.
