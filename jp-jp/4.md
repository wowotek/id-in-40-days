# Day 4 – 家族と友人

今日はインドネシア語で家族や友人について話す方法を学びます。これは個人的な会話に役立ちます！

---

## 👨‍👩‍👧‍👦 家族と友人の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| keluarga       | 家族 |
| ayah           | 父 |
| ibu            | 母 |
| anak           | 子供/息子/娘 |
| saudara        | 兄弟姉妹/親戚 |
| kakak          | 年上の兄弟姉妹 |
| adik           | 年下の兄弟姉妹 |
| teman          | 友人 |
| suami          | 夫 |
| istri          | 妻 |

---

## 🗣️ 家族と友人について話す

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Saya punya dua saudara laki-laki. | 私には2人の兄がいます。 |
| Ayah saya dokter.                 | 私の父は医者です。 |
| Ibu saya suka memasak.            | 私の母は料理が好きです。 |
| Ini teman saya.                   | こちらは私の友人です。 |
| Kami keluarga bahagia.            | 私たちは幸せな家族です。 |

---

## 🕵️ 会話例

**家族について話す:**

> **Anda:** Berapa saudara kamu?
> 
> **Teman:** Saya punya satu kakak perempuan dan dua adik laki-laki.
> 
> **Anda:** Oh, banyak ya.
> 
> **Teman:** Ya, keluarga besar.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私には妹がいます。
2. 私の母は先生です。
3. 彼は私の友人です。
4. 彼女は私の姉です。
5. あなたには兄弟姉妹がいますか？

✅ _解答キー:_

1. Saya punya adik perempuan.
2. Ibu saya guru.
3. Dia teman saya.
4. Dia kakak perempuan saya.
5. Kamu punya saudara?
