# Day 8 – 場所と道順

今日はインドネシア語で場所を尋ねたり道順を教えたりする方法を学びます。これは旅行中に役立ちます！

---

## 📍 場所と道順の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| di mana        | どこに/で |
| dekat          | 近い |
| jauh           | 遠い |
| kanan          | 右 |
| kiri           | 左 |
| lurus          | まっすぐ |
| belok          | 曲がる |
| jalan          | 道/通り |
| gedung         | 建物 |
| toko           | 店 |
| restoran       | レストラン |
| rumah sakit    | 病院 |

---

## 🗣️ 場所と道順を尋ねる・教える

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Di mana stasiun kereta?           | 駅はどこですか？ |
| Toko itu dekat sini.              | その店はここから近いです。 |
| Belok kanan di persimpangan.      | 交差点で右に曲がってください。 |
| Jalan terus sampai bertemu lampu merah. | 信号に当たるまでまっすぐ行ってください。 |
| Rumah sakit itu jauh dari sini.   | その病院はここから遠いです。 |

---

## 🕵️ 会話例

**道順を尋ねる:**

> **Anda:** Permisi, bisa tunjukkan jalan ke restoran?
> 
> **Orang:** Oh, restoran itu. Jalan lurus, lalu belok kiri di perempatan pertama. Dekat situ.
> 
> **Anda:** Terima kasih banyak.
> 
> **Orang:** Sama-sama.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. どこに住んでいますか？
2. 左に曲がってください。
3. 銀行は遠いです。
4. これは建物ですか？
5. まっすぐ行ってください。

✅ _解答キー:_

1. Di mana kamu tinggal?
2. Belok kiri.
3. Bank itu jauh.
4. Ini gedung?
5. Jalan lurus.
