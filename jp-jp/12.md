# Day 12 – 趣味

今日はインドネシア語で趣味について話す方法を学びます。これは新しい友人を作ったり、共通の興味を見つけたりするのに役立ちます！

---

## 🎨 趣味の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| hobi           | 趣味 |
| membaca        | 読む |
| menulis        | 書く |
| olahraga       | スポーツ/運動 |
| bermain        | 遊ぶ/演奏する |
| musik          | 音楽 |
| menonton       | 観る |
| film           | 映画 |
| jalan-jalan    | 散歩する/ぶらぶらする |
| memasak        | 料理する |
| melukis        | 絵を描く |
| berenang       | 泳ぐ |

---

## 🗣️ 趣味について話す

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Hobi saya membaca buku.           | 私の趣味は本を読むことです。 |
| Dia suka bermain musik.           | 彼/彼女は音楽を演奏するのが好きです。 |
| Kamu suka olahraga apa?           | あなたはどんなスポーツが好きですか？ |
| Kami sering menonton film.         | 私たちはよく映画を観ます。 |
| Saya suka jalan-jalan di pantai.  | 私はビーチを散歩するのが好きです。 |

---

## 🕵️ 会話例

**趣味について尋ねる:**

> **Anda:** Apa hobi kamu?
> 
> **Teman:** Hobi saya memasak dan melukis.
> 
> **Anda:** Wah, menarik sekali! Saya suka membaca.
> 
> **Teman:** Ya, membaca juga bagus.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私は泳ぐのが好きです。
2. 彼の趣味は音楽です。
3. あなたは書くのが好きですか？
4. 彼女はよく映画を観ます。
5. 私たちは運動が好きです。

✅ _解答キー:_

1. Saya suka berenang.
2. Hobinya musik.
3. Kamu suka menulis?
4. Dia sering menonton film.
5. Kami suka olahraga.
