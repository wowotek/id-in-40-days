# Day 20 – 未来の計画

今日はインドネシア語で未来の計画について話す方法を学びます。これは目標を共有したり、未来について議論したりするのに役立ちます！

---

## 🔮 未来の計画の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| rencana        | 計画 |
| masa depan     | 将来/未来 |
| ingin          | ～したい/～を望む |
| akan           | ～だろう (未来) |
| setelah        | ～の後 |
| sebelum        | ～の前 |
| menjadi        | ～になる |
| belajar        | 勉強する |
| bekerja        | 働く |
| berlibur       | 休暇をとる |

---

## 🗣️ 未来の計画について話す

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Saya punya rencana untuk masa depan. | 私は将来のための計画があります。 |
| Setelah kuliah, saya akan bekerja. | 大学卒業後、私は働きます。 |
| Dia ingin menjadi dokter.         | 彼/彼女は医者になりたいです。 |
| Kami akan berlibur tahun depan.   | 私たちは来年休暇をとります。 |
| Kamu mau belajar apa lagi?        | あなたは他に何を勉強したいですか？ |

---

## 🕵️ 会話例

**将来の計画について話す:**

> **Anda:** Apa rencanamu setelah lulus?
> 
> **Teman:** Saya akan bekerja di perusahaan teknologi.
> 
> **Anda:** Bagus sekali! Saya ingin menjadi pengusaha.
> 
> **Teman:** Semoga berhasil!

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私は旅行したいです。
2. 彼は来年結婚するでしょう。
3. 私たちの計画は何ですか？
4. 彼女は教師になりたいです。
5. 彼らは新しい家を建てるでしょう。

✅ _解答キー:_

1. Saya ingin jalan-jalan.
2. Dia akan menikah tahun depan.
3. Apa rencana kita?
4. Dia ingin menjadi guru.
5. Mereka akan membangun rumah baru.
