# Day 26 – 外食

今日はインドネシア語で外食について話す方法を学びます。これはレストランやカフェで注文したり、会話したりするのに役立ちます！

---

## 🍽️ 外食の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| restoran       | レストラン |
| kafe           | カフェ |
| pesan          | 注文する |
| makan          | 食べる |
| minum          | 飲む |
| menu           | メニュー |
| enak           | おいしい |
| pedas          | 辛い |
| manis          | 甘い |
| air             | 水 |
| nasi goreng    | ナシゴレン |
| mie goreng     | ミーゴレン |

---

## 🗣️ 外食の表現

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Mari kita makan di restoran itu.  | あのレストランで食べましょう。 |
| Saya mau pesan nasi goreng.       | ナシゴレンを注文したいです。 |
| Makanan ini sangat enak.          | この食べ物はとてもおいしいです。 |
| Kamu suka pedas?                  | 辛いものが好きですか？ |
| Bisakah saya minta air?           | 水をいただけますか？ |

---

## 🕵️ 会話例

**レストランで注文する:**

> **Anda:** Mau makan apa?
> 
> **Teman:** Saya mau mie goreng. Kamu?
> 
> **Anda:** Saya mau nasi goreng. Minumnya apa?
> 
> **Teman:** Saya mau teh es.
> 
> **Anda:** Oke, saya juga.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私はカフェに行きたいです。
2. このコーヒーは甘いです。
3. 彼は辛いものが好きではありません。
4. あなたはメニューを見ましたか？
5. 私たちは今食べましょう。

✅ _解答キー:_

1. Saya mau pergi ke kafe.
2. Kopi ini manis.
3. Dia tidak suka pedas.
4. Kamu sudah lihat menu?
5. Mari kita makan sekarang.
