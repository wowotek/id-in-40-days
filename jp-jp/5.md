# Day 5 – 日常生活

今日はインドネシア語で日常生活について話す方法を学びます。これは毎日の会話に役立ちます！

---

## ⏰ 日常生活の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| bangun         | 起きる |
| mandi          | シャワーを浴びる |
| sarapan        | 朝食を食べる |
| pergi ke kerja | 仕事に行く |
| makan siang    | 昼食を食べる |
| pulang         | 帰る |
| makan malam    | 夕食を食べる |
| tidur          | 寝る |
| setiap hari    | 毎日 |
| sekarang       | 今 |

---

## 🗣️ 日常生活について話す

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Saya bangun jam enam setiap hari. | 私は毎日6時に起きます。 |
| Dia sarapan roti.                 | 彼/彼女はパンで朝食をとります。 |
| Kami pergi ke kerja sekarang.     | 私たちは今仕事に行きます。 |
| Kamu mandi jam berapa?            | あなたは何時にシャワーを浴びますか？ |
| Mereka makan malam di rumah.      | 彼らは家で夕食をとります。 |

---

## 🕵️ 会話例

**一日のルーティンについて話す:**

> **Anda:** Apa yang kamu lakukan setiap pagi?
> 
> **Teman:** Saya bangun, mandi, lalu sarapan.
> 
> **Anda:** Jam berapa kamu pergi ke kerja?
> 
> **Teman:** Jam delapan pagi.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私は7時に朝食をとります。
2. 彼は今寝ています。
3. 私たちは毎日帰ります。
4. あなたは夜に何をしますか？
5. 彼女はシャワーを浴びています。

✅ _解答キー:_

1. Saya sarapan jam tujuh.
2. Dia tidur sekarang.
3. Kami pulang setiap hari.
4. Apa yang kamu lakukan di malam hari?
5. Dia sedang mandi.
