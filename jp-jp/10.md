# Day 10 – 天気

今日はインドネシア語で天気について話す方法を学びます。これは旅行の計画や日常会話に役立ちます！

---

## ☀️ 天気の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| cuaca          | 天気 |
| panas          | 暑い |
| dingin         | 寒い |
| hujan          | 雨/雨が降る |
| cerah          | 晴れ |
| berawan        | 曇り |
| berangin       | 風が強い |
| salju          | 雪/雪が降る |
| musim          | 季節 |
| kemarau        | 乾季 |
| hujan          | 雨季 |

---

## 🗣️ 天気について話す

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Cuaca hari ini cerah.             | 今日の天気は晴れです。 |
| Besok mungkin hujan.              | 明日は雨が降るかもしれません。 |
| Saya tidak suka cuaca dingin.     | 私は寒い天気が好きではありません。 |
| Di sini selalu panas.             | ここはいつも暑いです。 |
| Musim hujan sudah tiba.           | 雨季がやってきました。 |

---

## 🕵️ 会話例

**天気について話す:**

> **Anda:** Bagaimana cuaca hari ini?
> 
> **Teman:** Hari ini cerah dan panas.
> 
> **Anda:** Oh, bagus untuk pergi ke pantai.
> 
> **Teman:** Ya, mari kita pergi!

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 明日は曇りです。
2. 寒いですか？
3. ここは雨がよく降ります。
4. 私は暑い天気が好きです。
5. 雪が降っていますか？

✅ _解答キー:_

1. Besok berawan.
2. Dingin?
3. Di sini sering hujan.
4. Saya suka cuaca panas.
5. Salju turun?
