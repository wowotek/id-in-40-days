# Day 21 – 好き嫌いを表現する

今日はインドネシア語で好き嫌いを表現する方法を学びます。これは好みについて話すのに役立ちます！

---

## ❤️ 好き嫌いの語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| suka           | 好き |
| tidak suka     | 好きではない |
| cinta          | 大好き/愛する |
| benci          | 嫌い |
| makanan        | 食べ物 |
| minuman        | 飲み物 |
| musik          | 音楽 |
| film           | 映画 |
| buku           | 本 |
| olahraga       | スポーツ |

---

## 🗣️ 好き嫌いを表現する

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Saya suka makan nasi goreng.      | 私はナシゴレンを食べるのが好きです。 |
| Dia tidak suka kopi.              | 彼/彼女はコーヒーが好きではありません。 |
| Kamu cinta musik pop?             | あなたはポップミュージックが大好きですか？ |
| Kami benci sayuran.               | 私たちは野菜が嫌いです。 |
| Mereka suka membaca buku.         | 彼らは本を読むのが好きです。 |

---

## 🕵️ 会話例

**好みについて話す:**

> **Anda:** Kamu suka film horor?
> 
> **Teman:** Tidak, saya tidak suka film horor. Saya suka film komedi.
> 
> **Anda:** Oh, saya juga suka film komedi.
> 
> **Teman:** Bagus!

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私は水が好きです。
2. 彼はスポーツが好きではありません。
3. あなたはどんな食べ物が好きですか？
4. 彼女は本を読むのが大好きです。
5. 私たちは辛い食べ物が嫌いです。

✅ _解答キー:_

1. Saya suka air.
2. Dia tidak suka olahraga.
3. Makanan apa yang kamu suka?
4. Dia cinta membaca buku.
5. Kami benci makanan pedas.
