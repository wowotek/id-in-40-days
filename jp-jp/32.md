# 日 32: 家族と人間関係

## はじめに
32日目のレッスンへようこそ！今日は、家族と人間関係に関連する語彙や表現を学びます。これにより、家族のメンバーや個人的な関係について話すことができるようになります。

## 主要語彙

| 日本語 | インドネシア語 |
|---|---|
| 家族 | keluarga |
| 父 | ayah |
| 母 | ibu |
| 両親 | orang tua |
| 息子 | anak laki-laki |
| 娘 | anak perempuan |
| 兄/弟 | saudara laki-laki |
| 姉/妹 | saudara perempuan |
| 祖父 | kakek |
| 祖母 | nenek |
| 祖父母 | kakek-nenek |
| おじ | paman |
| おば | bibi |
| いとこ | sepupu |
| 夫 | suami |
| 妻 | istri |
| 友達 | teman |
| 女友達 | teman perempuan |
| 親戚 | kerabat |
| 関係 | hubungan |

## 便利なフレーズ

*   **大家族ですか？** (Apakah kamu punya keluarga besar?)
*   **兄弟は何人いますか？** (Berapa banyak saudara laki-laki dan perempuan yang kamu miliki?)
*   **私の母は教師です。** (Ibuku seorang guru.)
*   **私の父は医者です。** (Ayahku seorang dokter.)
*   **私は長男です。** (Saya anak laki-laki tertua.)
*   **彼女は私の妹です。** (Dia adik perempuan saya.)
*   **私たちは親戚です。** (Kami kerabat.)
*   **彼らは私の親友です。** (Mereka teman dekat saya.)
*   **私は家族と良好な関係を築いています。** (Saya punya hubungan yang baik dengan keluarga saya.)
*   **私は家族と時間を過ごすのが好きです。** (Saya suka menghabiskan waktu dengan keluarga saya.)

## 練習問題

1.  **次の文をインドネシア語に翻訳してください。**
    *   私の祖父母は村に住んでいます。
    *   私にはいとこが一人います。
    *   私の兄は結婚しています。

2.  **あなたの家族と個人的な関係を日本語で説明してください。**

## 会話例

**A:** 兄弟姉妹はいますか？
**B:** はい、兄が一人と妹が一人います。
**A:** すごいですね！よく一緒に時間を過ごしますか？
**B:** はい、とても仲が良いです。あなたはどうですか？
**A:** 私は一人っ子ですが、いとこがたくさんいます。

## まとめ
32日目のレッスンを完了おめでとうございます！これで家族と人間関係について話せるようになりました。これらの表現を完璧にマスターするために、練習を続けてください。
