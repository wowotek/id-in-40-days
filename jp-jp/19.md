# Day 19 – 過去の出来事

今日はインドネシア語で過去の出来事について話す方法を学びます。これは経験を共有したり、過去の物語を語ったりするのに役立ちます！

---

## 🕰️ 過去の出来事の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| kemarin        | 昨日 |
| minggu lalu    | 先週 |
| bulan lalu     | 先月 |
| tahun lalu     | 昨年 |
| sudah          | すでに/～した |
| belum          | まだ/～していない |
| pergi          | 行く |
| datang         | 来る |
| melihat        | 見る |
| makan          | 食べる |
| terjadi        | 起こる/発生する |

---

## 🗣️ 過去の出来事について話す

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Kemarin saya pergi ke pasar.      | 昨日、私は市場に行きました。 |
| Dia sudah makan.                  | 彼/彼女はすでに食べました。 |
| Minggu lalu kami melihat film baru. | 先週、私たちは新しい映画を観ました。 |
| Apa yang terjadi?                 | 何が起こったのですか？ |
| Saya belum datang ke Bali.        | 私はまだバリ島に行ったことがありません。 |

---

## 🕵️ 会話例

**過去の旅行について話す:**

> **Anda:** Kamu pergi ke mana minggu lalu?
> 
> **Teman:** Saya pergi ke Yogyakarta.
> 
> **Anda:** Wah, kamu sudah melihat Candi Borobudur?
> 
> **Teman:** Tentu saja! Sangat indah.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私は昨日働きました。
2. 彼女はまだ来ていません。
3. 私たちは昨年新しい家を買いました。
4. 何が起こったのですか？
5. 彼はすでに食べましたか？

✅ _解答キー:_

1. Saya bekerja kemarin.
2. Dia belum datang.
3. Kami membeli rumah baru tahun lalu.
4. Apa yang terjadi?
5. Dia sudah makan?
