## 2. Discussing Technology Use

Use these structures to talk about how you use technology.

*   **Talking about usage:**
    *   `for work` (untuk pekerjaan)
    *   `for communication` (untuk komunikasi)
    *   `for entertainment` (untuk hiburan)

    *Examples:*
    *   `I use my computer for work.` (Saya menggunakan komputer saya untuk pekerjaan.)
    *   `She uses social media for communication.` (Dia menggunakan media sosial untuk komunikasi.)

*   **Asking about habits:**
    *   `Do you use the internet often?` (Apakah kamu sering menggunakan internet?)
    *   `How do you communicate with your family?` (Bagaimana kamu berkomunikasi dengan keluargamu?)

## 3. Common Expressions about Communication

*   `Call me.` (Telepon saya.)
*   `Text me.` (Kirim pesan kepada saya.)
*   `Email me.` (Email saya.)
*   `Stay in touch.` (Tetap berhubungan.)

## 4. Useful Phrases

*   `I use my phone every day.` (Saya menggunakan telepon saya setiap hari.)
*   `Do you have internet access?` (Apakah kamu punya akses internet?)
*   `I will send you an email.` (Saya akan mengirim email kepadamu.)
*   `Let's chat online.` (Mari kita mengobrol daring.)

## 5. Mini-Dialogue

**A:** `How do you usually communicate with your friends?` (Bagaimana kamu biasanya berkomunikasi dengan teman-temanmu?)
**B:** `I usually text them or use social media apps.` (Saya biasanya mengirim pesan kepada mereka atau menggunakan aplikasi media sosial.)
**A:** `Do you often use the internet for news?` (Apakah kamu sering menggunakan internet untuk berita?)
**B:** `Yes, I browse news websites every morning.` (Ya, saya menjelajah situs web berita setiap pagi.)
