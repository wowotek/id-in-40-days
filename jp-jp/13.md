# Day 13 – 学校と仕事

今日はインドネシア語で学校や仕事について話す方法を学びます。これは日常生活の会話に役立ちます！

---

## 📚 学校と仕事の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| sekolah        | 学校 |
| belajar        | 勉強する |
| guru           | 先生 |
| murid          | 生徒 |
| kuliah         | 大学/講義 |
| kerja          | 仕事/働く |
| kantor         | オフィス |
| pekerjaan      | 職業/仕事 |
| karyawan       | 従業員 |
| bos            | 上司 |

---

## 🗣️ 学校と仕事について話す

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Saya belajar bahasa Indonesia di sekolah. | 私は学校でインドネシア語を勉強しています。 |
| Dia seorang guru di sekolah dasar. | 彼/彼女は小学校の先生です。 |
| Kami pergi ke kantor setiap pagi. | 私たちは毎朝オフィスに行きます。 |
| Apa pekerjaan kamu?               | あなたの仕事は何ですか？ |
| Murid-murid sedang belajar.       | 生徒たちは勉強しています。 |

---

## 🕵️ 会話例

**仕事について話す:**

> **Anda:** Kamu kerja di mana?
> 
> **Teman:** Saya kerja di kantor di pusat kota.
> 
> **Anda:** Oh, apa pekerjaan kamu?
> 
> **Teman:** Saya seorang programmer.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私は学生です。
2. 彼女は病院で働いています。
3. 私の先生はとても優しいです。
4. あなたは学校で何を勉強しますか？
5. 私たちはオフィスに行きません。

✅ _解答キー:_

1. Saya seorang murid.
2. Dia kerja di rumah sakit.
3. Guru saya sangat baik.
4. Apa yang kamu belajar di sekolah?
5. Kami tidak pergi ke kantor.
