# Day 23 – 日常のルーティン

今日はインドネシア語で日常のルーティンについて話す方法を学びます。これは毎日の習慣を説明するのに役立ちます！

---

## ⏰ 日常のルーティンの語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| bangun tidur   | 起きる |
| sarapan        | 朝食をとる |
| makan siang    | 昼食をとる |
| makan malam    | 夕食をとる |
| bekerja        | 働く |
| belajar        | 勉強する |
| mandi          | シャワーを浴びる/入浴する |
| pergi ke       | ～へ行く |
| pulang         | 帰宅する |
| menonton TV    | テレビを見る |
| membaca buku   | 本を読む |

---

## 🗣️ 日常のルーティンについて話す

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Setiap pagi saya bangun tidur jam enam. | 私は毎朝6時に起きます。 |
| Dia sarapan dengan roti dan kopi. | 彼/彼女はパンとコーヒーで朝食をとります。 |
| Kami makan siang di kantor.       | 私たちはオフィスで昼食をとります。 |
| Setelah bekerja, dia pulang ke rumah. | 仕事の後、彼/彼女は家に帰ります。 |
| Mereka suka menonton TV di malam hari. | 彼らは夜にテレビを見るのが好きです。 |

---

## 🕵️ 会話例

**一日のルーティンについて尋ねる:**

> **Anda:** Apa rutinitas pagimu?
> 
> **Teman:** Saya bangun, mandi, lalu sarapan.
> 
> **Anda:** Lalu, kamu pergi ke mana?
> 
> **Teman:** Saya pergi ke kantor jam delapan.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私は毎晩本を読みます。
2. 彼は昼食を食べる。
3. あなたは何時に起きますか？
4. 私たちは学校に行きます。
5. 彼女はシャワーを浴びています。

✅ _解答キー:_

1. Saya membaca buku setiap malam.
2. Dia makan siang.
3. Jam berapa kamu bangun tidur?
4. Kami pergi ke sekolah.
5. Dia sedang mandi.
