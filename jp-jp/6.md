# Day 6 – 食べ物と飲み物

今日はインドネシア語で食べ物や飲み物について話す方法を学びます。これはレストランや市場で役立ちます！

---

## 🍎 食べ物と飲み物の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| makanan        | 食べ物 |
| minuman        | 飲み物 |
| nasi           | ご飯 |
| ayam           | 鶏肉 |
| ikan           | 魚 |
| sayur          | 野菜 |
| buah           | 果物 |
| air            | 水 |
| teh            | お茶 |
| kopi           | コーヒー |
| suka           | 好き |
| tidak suka     | 好きではない |

---

## 🗣️ 食べ物と飲み物について話す

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Saya suka nasi goreng.            | 私はナシゴレンが好きです。 |
| Kamu mau minum apa?               | あなたは何を飲みたいですか？ |
| Dia tidak suka ikan.              | 彼/彼女は魚が好きではありません。 |
| Ini buah yang segar.              | これは新鮮な果物です。 |
| Kami makan ayam dan sayur.        | 私たちは鶏肉と野菜を食べます。 |

---

## 🕵️ 会話例

**レストランで注文する:**

> **Anda:** Mau makan apa?
> 
> **Teman:** Saya mau nasi goreng dan teh.
> 
> **Anda:** Oke. Saya mau ikan dan air.
> 
> **Teman:** Selamat makan!

---

## 🧠 練習

インドネシア語に翻訳してください：

1. 私はコーヒーが好きです。
2. あなたはどんな食べ物が好きですか？
3. これは水ですか？
4. 彼らは野菜を食べます。
5. 私はお茶が好きではありません。

✅ _解答キー:_

1. Saya suka kopi.
2. Makanan apa yang kamu suka?
3. Ini air?
4. Mereka makan sayur.
5. Saya tidak suka teh.
