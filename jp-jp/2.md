# Day 2 – あいさつと基本表現

今日はインドネシア語のあいさつと基本的な表現を学びます。これらのフレーズは日常会話でとても役立ちます！

---

## 👋 あいさつと基本表現の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| selamat pagi   | おはようございます |
| selamat siang  | こんにちは (午前中) |
| selamat sore   | こんにちは (午後) |
| selamat malam  | こんばんは |
| terima kasih   | ありがとう |
| sama-sama       | どういたしまして |
| maaf           | ごめんなさい/すみません |
| permisi        | すみません (呼びかけ) |
| ya             | はい |
| tidak          | いいえ |
| oke            | オーケー |

---

## 🗣️ 基本的な表現

| インドネシア語 | 日本語 |
|-----------------------------------|------------------------------------|
| Selamat pagi, Ibu.               | おはようございます、お母さん。 |
| Terima kasih banyak.              | 本当にありがとうございます。 |
| Maaf, saya tidak mengerti.        | すみません、わかりません。 |
| Permisi, ada toilet di mana?      | すみません、トイレはどこですか？ |
| Ya, saya mengerti.                | はい、わかりました。 |

---

## 🕵️ 会話例

**レストランで:**

> **Anda:** Permisi, bisa bantu?
> 
> **Pelayan:** Ya, ada apa?
> 
> **Anda:** Terima kasih banyak.
> 
> **Pelayan:** Sama-sama.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. こんにちは（午後）。
2. どういたしまして。
3. ごめんなさい。
4. はい。
5. いいえ、結構です。

✅ _解答キー:_

1. Selamat sore.
2. Sama-sama.
3. Maaf.
4. Ya.
5. Tidak, terima kasih.
