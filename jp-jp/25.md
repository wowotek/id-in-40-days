# Day 25 – ショッピングと値段交渉

今日はインドネシア語で買い物をして値段交渉をする方法を学びます。これは市場や露店で役立ちます！

---

## 🛍️ ショッピングと値段交渉の語彙

| インドネシア語 | 日本語 |
|----------------|--------------------|
| belanja        | 買い物をする |
| harga          | 価格 |
| berapa         | いくら |
| mahal          | 高い |
| murah          | 安い |
| tawar          | 値段交渉する |
| diskon         | 割引 |
| uang           | お金 |
| kembalian      | お釣り |
| beli           | 買う |
| jual           | 売る |

---

## 🗣️ ショッピングと値段交渉の表現

| インドネシア語 | 日本語 |
|-----------------------------------|----------------------------|
| Berapa harga baju ini?            | この服はいくらですか？ |
| Bisa kasih diskon?                | 割引してもらえますか？ |
| Ini terlalu mahal.                | これは高すぎます。 |
| Saya mau beli ini dengan harga murah. | 私はこれを安く買いたいです。 |
| Ada uang kembalian?               | お釣りはありますか？ |

---

## 🕵️ 会話例

**市場で値段交渉する:**

> **Anda:** Berapa harga mangga ini, Bu?
> 
> **Penjual:** Dua puluh ribu rupiah per kilo.
> 
> **Anda:** Aduh, mahal sekali. Bisa tawar, Bu?
> 
> **Penjual:** Lima belas ribu saja, ya?
> 
> **Anda:** Oke, saya ambil. Terima kasih.

---

## 🧠 練習

インドネシア語に翻訳してください：

1. その靴はいくらですか？
2. 割引はありますか？
3. これは安いです。
4. 私は値段交渉したいです。
5. お釣りは要りません。

✅ _解答キー:_

1. Berapa harga sepatu itu?
2. Ada diskon?
3. Ini murah.
4. Saya mau tawar.
5. Tidak perlu uang kembalian.
