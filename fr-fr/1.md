# Jour 1 – Présentations

Aujourd'hui, vous allez apprendre à vous présenter en indonésien. Il est facile de se présenter en utilisant des phrases simples !

---

## 🤝 Vocabulaire de Présentation

| Indonésien | Français |
|------------|------------------|
| nama       | nom              |
| saya       | je               |
| kamu       | tu/vous          |
| dia        | il/elle          |
| dari       | de (origine)     |
| tinggal    | vivre            |
| di         | à/en             |
| apa        | quoi             |
| siapa      | qui              |
| bagaimana  | comment          |

---

## 🗣️ Phrases pour se Présenter

| Indonésien | Français |
|-----------------------------------|---------------------------------------|
| Nama saya Pierre.                 | Mon nom est Pierre.                   |
| Saya dari Prancis.                | Je viens de France.                   |
| Kamu siapa?                       | Qui es-tu ?                           |
| Dia tinggal di Jakarta.           | Il/Elle habite à Jakarta.             |
| Apa kabar?                        | Comment ça va ?                       |

---

## 🕵️ Dialogue Exemple

**Rencontrer quelqu'un de nouveau :**

> **Vous :** Nama kamu siapa?
> 
> **Ami :** Nama saya Lena. Kamu?
> 
> **Vous :** Nama saya Marc. Saya dari Prancis.
> 
> **Ami :** Selamat datang di Indonesia!

---

## 🧠 Pratique

Traduire en indonésien :

1. Mon nom est Sophie.
2. Je viens d'Indonésie.
3. Qui est-il ?
4. Où habitez-vous ?
5. Je vais bien.

✅ _Clé de Réponses :_

1. Nama saya Sophie.
2. Saya dari Indonesia.
3. Dia siapa?
4. Kamu tinggal di mana?
5. Baik.
