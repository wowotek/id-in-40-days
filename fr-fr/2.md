# Jour 2 – Salutations et expressions de base

Aujourd'hui, vous allez apprendre les salutations et les expressions de base en indonésien. Ces phrases sont très utiles dans la conversation quotidienne !

---

## 👋 Vocabulaire des Salutations et Expressions de Base

| Indonésien | Français |
|----------------|--------------------------|
| selamat pagi   | bonjour (matin)          |
| selamat siang  | bonjour (milieu de journée)|
| selamat sore   | bon après-midi           |
| selamat malam  | bonne nuit/bonsoir       |
| terima kasih   | merci                    |
| sama-sama       | de rien                  |
| maaf           | désolé/excusez-moi        |
| permisi        | pardon (pour attirer l'attention)|
| ya             | oui                      |
| tidak          | non                      |
| oke            | ok                       |

---

## 🗣️ Expressions de Base

| Indonésien | Français |
|-----------------------------------|---------------------------------------|
| Selamat pagi, Bapak.              | Bonjour, monsieur.                    |
| Terima kasih banyak.              | Merci beaucoup.                       |
| Maaf, saya tidak mengerti.        | Désolé, je ne comprends pas.          |
| Permisi, toiletnya di mana?       | Excusez-moi, où sont les toilettes ?  |
| Ya, saya mengerti.                | Oui, je comprends.                    |

---

## 🕵️ Dialogue Exemple

**Dans un restaurant :**

> **Vous :** Permisi, bisa bantu?
> 
> **Serveur :** Ya, ada apa?
> 
> **Vous :** Terima kasih banyak.
> 
> **Serveur :** Sama-sama.

---

## 🧠 Pratique

Traduire en indonésien :

1. Bon après-midi.
2. De rien.
3. Désolé.
4. Oui.
5. Non, merci.

✅ _Clé de Réponses :_

1. Selamat sore.
2. Sama-sama.
3. Maaf.
4. Ya.
5. Tidak, terima kasih.
