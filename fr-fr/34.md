## 2. Discuter de l'utilisation de la technologie

Utilisez ces structures pour parler de la façon dont vous utilisez la technologie.

*   **Parler de l'utilisation :**
    *   `pour le travail` (untuk pekerjaan)
    *   `pour la communication` (untuk komunikasi)
    *   `pour le divertissement` (untuk hiburan)

    *Exemples:*
    *   `J'utilise mon ordinateur pour le travail.` (Saya menggunakan komputer saya untuk pekerjaan.)
    *   `Elle utilise les médias sociaux pour la communication.` (Dia menggunakan media sosial untuk komunikasi.)

*   **Poser des questions sur les habitudes :**
    *   `Utilises-tu souvent internet ?` (Apakah kamu sering menggunakan internet?)
    *   `Comment communiques-tu avec ta famille ?` (Bagaimana kamu berkomunikasi dengan keluargamu?)

## 3. Expressions courantes sur la communication

*   `Appelle-moi.` (Telepon saya.)
*   `Envoie-moi un message.` (Kirim pesan kepada saya.)
*   `Envoie-moi un e-mail.` (Email saya.)
*   `Rester en contact.` (Tetap berhubungan.)

## 4. Phrases utiles

*   `J'utilise mon téléphone tous les jours.` (Saya menggunakan telepon saya setiap hari.)
*   `Avez-vous accès à internet ?` (Apakah kamu punya akses internet?)
*   `Je t'enverrai un e-mail.` (Saya akan mengirim email kepadamu.)
*   `Discutons en ligne.` (Mari kita mengobrol daring.)

## 5. Mini-dialogue

**A:** `Comment communiques-tu habituellement avec tes amis ?` (Bagaimana kamu biasanya berkomunikasi dengan teman-temanmu?)
**B:** `Je leur envoie généralement des messages ou utilise des applications de médias sociaux.` (Saya biasanya mengirim pesan kepada mereka atau menggunakan aplikasi media sosial.)
**A:** `Utilises-tu souvent internet pour les actualités ?` (Apakah kamu sering menggunakan internet untuk berita?)
**B:** `Oui, je navigue sur les sites d'actualités tous les matins.` (Ya, saya menjelajah situs web berita setiap pagi.)

## Exercice

Traduisez les phrases suivantes en indonésien :

1.  J'ai besoin de vérifier mes e-mails.
2.  Elle m'a envoyé un message.
3.  L'internet est très rapide ici.
