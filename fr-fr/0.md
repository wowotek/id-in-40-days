# Jour 0 – Introduction

Bienvenue dans le cours de 40 jours pour maîtriser l'indonésien ! Ce livre vous guidera pas à pas, chaque jour, de façon pratique et conviviale.

---

## Comment utiliser ce livre
- Avancez d'une leçon par jour.
- Pratiquez à voix haute les exemples et exercices.
- En cas de doute, rejoignez la communauté pour poser vos questions.
