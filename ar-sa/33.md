# اليوم 33: الاحتفالات والأعياد

## جدول المحتويات

1.  **مفردات العطلات**
    *   أسماء الأعياد الشائعة (رأس السنة، عيد الفطر، عيد الميلاد، ديوالي، إلخ.)
    *   كلمات متعلقة بالاحتفال (حفلة، هدية، كعكة، تزيين)
2.  **مناقشة تقاليد العطلات**
    *   الحديث عن الأنشطة خلال العطلات (زيارة العائلة، تناول طعام خاص)
    *   التعبير عن الأمنيات الطيبة للأعياد
3.  **تعبيرات شائعة حول الاحتفالات**
    *   "سنة جديدة سعيدة"، "عيد ميلاد مجيد"، "عيد مبارك"
    *   "استمتع بإجازتك"
4.  **عبارات مفيدة**
    *   "ما هي خططك للعطلة؟"
    *   "نحن نحتفل بعيد الفطر كل عام."
    *   "أحب تقديم الهدايا."
    *   "كانت الحفلة ممتعة."
5.  **حوار قصير**
    *   محادثة حول خطط وتقاليد العطلات.

## 1. مفردات العطلات

تعلم الكلمات الأساسية المتعلقة بالاحتفالات والأعياد.

| العربية             | الإندونيسية    |
|---------------------|----------------|
| رأس السنة          | Tahun Baru     |
| عيد الفطر           | Idul Fitri     |
| عيد الميلاد (الكريسماس) | Natal          |
| ديوالي              | Diwali         |
| رأس السنة الصينية   | Imlek          |
| يوم الاستقلال       | Hari Kemerdekaan |
| عيد ميلاد           | ulang tahun    |
| عطلة                | hari libur     |
| حفلة                | pesta          |
| هدية                | hadiah         |
| كعكة                | kue            |
| تزيين               | menghias       |
| احتفال              | merayakan      |

## 2. مناقشة تقاليد العطلات

استخدم هذه التراكيب للحديث عن أنشطة وتقاليد العطلات.

*   **الحديث عن الأنشطة:**
    *   `زيارة العائلة` (mengunjungi keluarga)
    *   `تناول طعام خاص` (makan makanan khusus)
    *   `تبادل الهدايا` (bertukar hadiah)

    *أمثلة:*
    *   `نحن نزور العائلة خلال عيد الفطر.` (Kami mengunjungi keluarga saat Idul Fitri.)
    *   `يأكلون كعكة خاصة لعيد الميلاد.` (Mereka makan kue khusus untuk Natal.)

*   **التعبير عن الأمنيات الطيبة:**
    *   `سنة جديدة سعيدة!` (Selamat Tahun Baru!)
    *   `عيد ميلاد مجيد!` (Selamat Natal!)
    *   `عيد مبارك!` (Selamat Idul Fitri!)

## 3. تعبيرات شائعة حول الاحتفالات

*   `عيد ميلاد سعيد!` (Selamat ulang tahun!)
*   `استمتع بإجازتك!` (Selamat berlibur!)
*   `أتمنى لك وقتًا ممتعًا!` (Selamat bersenang-senang!)

## 4. عبارات مفيدة

*   `ما هي خططك للعطلة؟` (Apa rencanamu untuk liburan?)
*   `نحن نحتفل بعيد الفطر كل عام.` (Kami merayakan Idul Fitri setiap tahun.)
*   `أحب تقديم الهدايا.` (Saya suka memberi hadiah.)
*   `كانت الحفلة ممتعة.` (Pestanya menyenangkan.)

## 5. حوار قصير

**أ:** `ما هي خططك لرأس السنة؟` (Apa rencanamu untuk Tahun Baru?)
**ب:** `سأزور عائلتي وسنقيم حفلة.` (Saya akan mengunjungi keluarga saya dan kami akan mengadakan pesta.)
**أ:** `هذا يبدو ممتعًا! هل ستبادلون الهدايا؟` (Kedengarannya menyenangkan! Akankah kalian bertukar hadiah?)
**ب:** `نعم، نفعل ذلك دائمًا. وسنأكل كعكة خاصة.` (Ya, kami selalu begitu. Dan kami akan makan kue khusus.)
