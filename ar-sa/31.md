# اليوم 31: الحديث عن العمل والمدرسة

## مقدمة
أهلاً بك في درس اليوم 31! سنتعلم اليوم المفردات والتعبيرات المتعلقة بالعمل والمدرسة. سيساعدك هذا على التحدث عن أنشطتك اليومية المتعلقة بالعمل أو الدراسة.

## المفردات الأساسية

| العربية | الإندونيسية |
|---|---|
| عمل | kerja |
| وظيفة | pekerjaan |
| شركة | perusahaan |
| مكتب | kantor |
| زميل عمل | rekan kerja |
| مدير | manajer |
| اجتماع | rapat |
| مشروع | proyek |
| مدرسة | sekolah |
| جامعة | universitas |
| طالب | siswa/mahasiswa |
| مدرس/أستاذ | guru/dosen |
| فصل دراسي | kelas |
| درس | pelajaran |
| واجب منزلي | pekerjaan rumah |
| دراسة | belajar |
| امتحان | ujian |
| مكتبة | perpustakaan |
| استراحة | istirahat |
| عطلة | liburan |

## عبارات مفيدة

*   **ماذا تعمل؟** (Apa pekerjaanmu?)
*   **أنا أعمل في شركة.** (Saya bekerja di perusahaan.)
*   **أنا طالب.** (Saya seorang siswa/mahasiswa.)
*   **أين تدرس؟** (Di mana kamu belajar?)
*   **لدي اجتماع غداً.** (Saya ada rapat besok.)
*   **أحب وظيفتي.** (Saya suka pekerjaan saya.)
*   **المدرسة مهمة.** (Sekolah itu penting.)
*   **هل أكملت واجباتك المدرسية؟** (Apakah kamu sudah menyelesaikan pekerjaan rumahmu?)
*   **نحن نتعلم لغة جديدة.** (Kami sedang belajar bahasa baru.)
*   **كم ساعة تعمل في اليوم؟** (Berapa jam kamu bekerja sehari?)

## تمارين

1.  **ترجم الجمل التالية إلى الإندونيسية:**
    *   أذهب إلى الجامعة كل يوم.
    *   مديري لطيف جداً.
    *   ما هو موضوع دراستك المفضلة؟

2.  **صف روتينك اليومي في العمل أو المدرسة باللغة العربية.**

## مثال حوار

**أ:** مرحباً! ماذا تدرسين في الجامعة؟
**ب:** مرحباً! أنا أدرس الاقتصاد. وماذا عنك؟ هل تعمل؟
**أ:** نعم، أنا أعمل كمهندس برمجيات في شركة تكنولوجيا.
**ب:** هذا مثير للاهتمام! هل تحب عملك؟
**أ:** نعم، أحبه كثيراً. إنه تحدي وممتع.

## الخلاصة
تهانينا على إكمال درس اليوم 31! لقد تعلمت الآن كيفية التحدث عن العمل والمدرسة. استمر في ممارسة هذه التعبيرات لإتقانها تماماً.
