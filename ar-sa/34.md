# اليوم 34: التكنولوجيا والاتصالات

## جدول المحتويات

1.  **مفردات التكنولوجيا**
    *   كلمات للأجهزة الشائعة (هاتف، حاسوب، إنترنت، بريد إلكتروني، وسائل التواصل الاجتماعي)
    *   أفعال متعلقة بالتكنولوجيا (إرسال، استقبال، تصفح، كتابة)
2.  **مناقشة استخدام التكنولوجيا**
    *   الحديث عن كيفية استخدامك للتكنولوجيا (للعمل، للاتصال، للترفيه)
    *   السؤال عن عادات الآخرين في استخدام التكنولوجيا
3.  **تعبيرات شائعة حول الاتصالات**
    *   "اتصل بي"، "أرسل لي رسالة نصية"، "أرسل لي بريدًا إلكترونيًا"
    *   "ابق على اتصال"
4.  **عبارات مفيدة**
    *   "أستخدم هاتفي كل يوم."
    *   "هل لديك وصول إلى الإنترنت؟"
    *   "سأرسل لك بريدًا إلكترونيًا."
    *   "لنتحدث عبر الإنترنت."
5.  **حوار قصير**
    *   محادثة حول استخدام التكنولوجيا للتواصل.

## 1. مفردات التكنولوجيا

تعلم الكلمات الأساسية المتعلقة بالتكنولوجيا والاتصالات.

| العربية             | الإندونيسية    |
|---------------------|----------------|
| هاتف                | telepon        |
| حاسوب               | komputer       |
| إنترنت              | internet       |
| بريد إلكتروني       | email          |
| وسائل التواصل الاجتماعي | media sosial   |
| موقع إلكتروني       | situs web      |
| تطبيق (تطبيق)      | aplikasi       |
| رسالة               | pesan          |
| إرسال               | mengirim       |
| استقبال            | menerima       |
| تصفح               | menjelajah     |
| كتابة              | mengetik       |
| الاتصال (هاتفي)    | menelepon      |
| إرسال رسالة نصية    | mengirim pesan |
| التواصل            | berkomunikasi  |

## 2. مناقشة استخدام التكنولوجيا

استخدم هذه التراكيب للحديث عن كيفية استخدامك للتكنولوجيا.

*   **الحديث عن الاستخدام:**
    *   `للعمل` (untuk pekerjaan)
    *   `للاتصال` (untuk komunikasi)
    *   `للترفيه` (untuk hiburan)

    *أمثلة:*
    *   `أستخدم حاسوبي للعمل.` (Saya menggunakan komputer saya untuk pekerjaan.)
    *   `تستخدم وسائل التواصل الاجتماعي للاتصال.` (Dia menggunakan media sosial untuk komunikasi.)

*   **السؤال عن العادات:**
    *   `هل تستخدم الإنترنت كثيرًا؟` (Apakah kamu sering menggunakan internet?)
    *   `كيف تتواصل مع عائلتك؟` (Bagaimana kamu berkomunikasi dengan keluargamu?)

## 3. تعبيرات شائعة حول الاتصالات

*   `اتصل بي.` (Telepon saya.)
*   `أرسل لي رسالة نصية.` (Kirim pesan kepada saya.)
*   `أرسل لي بريدًا إلكترونيًا.` (Email saya.)
*   `ابق على اتصال.` (Tetap berhubungan.)

## 4. عبارات مفيدة

*   `أستخدم هاتفي كل يوم.` (Saya menggunakan telepon saya setiap hari.)
*   `هل لديك وصول إلى الإنترنت؟` (Apakah kamu punya akses internet?)
*   `سأرسل لك بريدًا إلكترونيًا.` (Saya akan mengirim email kepadamu.)
*   `لنتحدث عبر الإنترنت.` (Mari kita mengobrol daring.)

## 5. حوار قصير

**أ:** `كيف تتواصل عادةً مع أصدقائك؟` (Bagaimana kamu biasanya berkomunikasi dengan teman-temanmu?)
**ب:** `عادةً ما أرسل لهم رسائل نصية أو أستخدم تطبيقات وسائل التواصل الاجتماعي.` (Saya biasanya mengirim pesan kepada mereka atau menggunakan aplikasi media sosial.)
**أ:** `هل تستخدم الإنترنت غالبًا للأخبار؟` (Apakah kamu sering menggunakan internet untuk berita?)
**ب:** `نعم، أتصفح مواقع الأخبار كل صباح.` (Ya, saya menjelajah situs web berita setiap pagi.)

## تمرين

ترجم الجمل التالية إلى الإندونيسية:

1.  أحتاج إلى التحقق من بريدي الإلكتروني.
2.  لقد أرسلت لي رسالة.
3.  الإنترنت هنا سريع جدًا.

**مفتاح الإجابة:**

1.  Saya perlu memeriksa email saya.
2.  Dia mengirimi saya pesan.
3.  Internet di sini sangat cepat.
