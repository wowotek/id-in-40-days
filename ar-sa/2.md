# اليوم 2 – التحيات الأساسية والمقدمات (Basic Greetings & Introductions)

تُعد القدرة على تحية الناس وتقديم نفسك من الخطوات الأولى لإتقان أي لغة. في اللغة الإندونيسية، التحيات بسيطة وودودة ومرنة بحيث يمكنك استخدامها يوميًا.

---

## التحيات الشائعة (Common Greetings)

| الإندونيسية         | المعنى                      | ملاحظات                       |
| ------------------- | -------------------------- | --------------------------- |
| **Halo**            | مرحباً                      | عالمية وغير رسمية.        |
| **Selamat pagi**    | صباح الخير                 | تُستخدم حتى حوالي الساعة 11 صباحاً. |
| **Selamat siang**   | نهارك سعيد / بعد الظهر المبكر | من حوالي الساعة 11 صباحاً إلى 3 مساءً. |
| **Selamat sore**    | مساء الخير / المساء         | من حوالي الساعة 3 مساءً حتى غروب الشمس. |
| **Selamat malam**   | مساء الخير / الليل          | بعد غروب الشمس.             |
| **Apa kabar?**      | كيف حالك؟                  | غير رسمية وودودة.         |
| **Baik.**           | أنا بخير.                  | رد قياسي.                 |
| **Baik-baik saja.** | أنا بخير تماماً.          | أكثر رسمية قليلاً.       |

---

## تقديم نفسك (Introducing Yourself)

| الإنجليزية             | الإندونيسية                           | مثال                       |
| ------------------- | ------------------------------------ | ----------------------------- |
| My name is...       | **Nama saya...**                     | Nama saya John. (اسمي جون) |
| I am...             | **Saya...**                          | Saya pelajar. (أنا طالب) |
| Nice to meet you    | **Senang bertemu denganmu**          | مهذب وودود                  |
| Where are you from? | **Dari mana?** / **Asal dari mana?** | غير رسمي ومفيد              |
| I’m from...         | **Saya dari...**                     | Saya dari Amerika. (أنا من أمريكا) |

---

## توديع (Saying Goodbye)

| الإندونيسية         | المعنى                           | ملاحظات                               |
| ------------------- | --------------------------------- | ------------------------------------- |
| **Sampai jumpa!**   | أراك!                             | حرفياً: "حتى نلتقي مرة أخرى"       |
| **Sampai nanti!**   | أراك لاحقاً!                     | "حتى وقت لاحق"                      |
| **Selamat tinggal** | وداعاً (عندما تبقى *أنت*)        | تُستخدم عندما يغادر الشخص الآخر     |
| **Selamat jalan**   | وداعاً (عندما يبقى *هو/هي*)     | تُستخدم عندما تغادر *أنت*            |

# جمل تدريبية (Practice Sentences)

قل هذه بصوت عالٍ. الممارسة تؤدي إلى الطلاقة!

- Halo, nama saya Anna.
- Selamat pagi! Apa kabar?
- Saya dari Jepang.
- Senang bertemu denganmu!
- Sampai jumpa besok!
