## 🤝 Contributing

Do you speak a language not yet covered?  
Help us make **Bahasa Indonesia accessible worldwide** by contributing translations, reviews, or cultural improvements.

### 🛠️ How to Contribute

1. **Fork** this repository  
2. **Duplicate an existing language folder** (e.g. copy `en-us/` → `your-language-code/`)
3. **Translate** or **revise** the lessons in your language, starting from `0.md` to `40.md`
4. **Keep it human** – Improve AI-generated drafts with natural, localized expressions
5. Submit a **Pull Request**

> 📌 Even contributing **just one day** helps the movement!

---

### 🌐 Language Contribution Guidelines

- Use **ISO language-country codes** for folder names (e.g. `es-es`, `de-de`, `fr-fr`)
- Keep the file structure consistent (`0.md`, `1.md`, ..., `40.md`)
- You may localize `README.md` inside your language folder if needed
- When in doubt, ask in our [Discord Community](https://discord.gg/3VA2nf2CxV)
